# Журнал сессий (records)

Здесь хранятся записи каждой сессии-роли. Это **единственная память эксперимента** между
сессиями — обязательно веди записи по актуальному шаблону.

## Структура

```
records/
  README.md              — этот файл
  _template.md           — шаблон записи сессии (4-этапный цикл А/Б/В/Г)
  L04/                   — уровень 4/10
    game-designer.md
    graphic-designer.md
    balancer.md
    sound-designer.md
  ...
```

## Правила 4-этапного цикла (А / Б / В / Г)

- **Одна роль = один файл** в папке своего уровня (`records/L04/game-designer.md`).
- Запись создаётся **по шаблону** `records/_template.md`.
- В начале сессии агент обязан прочитать записи предыдущих ролей.
- Запись фиксирует:
  1. Работа роли (Этап А)
  2. Первоначальный код программиста (Этап Б)
  3. **3 проблемы проекта от Критика** и 3 вопроса пользователю с 4 вариантами (A, B, C + D «Оставить так») + ответы пользователя (Этап В)
  4. Коррективы и автотесты программиста по ответам (Этап Г)
