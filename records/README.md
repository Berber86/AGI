# Журнал сессий (records)

Здесь хранятся записи каждой сессии-роли. Это **единственная память эксперимента** между
сессиями — обязательно веди записи.

## Структура

```
records/
  README.md              — этот файл (как вести журнал)
  _template.md           — шаблон записи одной сессии
  L01/                  — уровень 1/10
    master-of-all-trades.md
  L02/                  — уровень 2/10
    game-designer.md
    programmer.md
  ...
```

## Правила

- **Одна роль = один файл** в папке своего уровня (`L03/graphic-designer.md`).
- Запись создаётся **по шаблону** `records/_template.md`.
- **3 вопроса пользователю** (с вариантами ответов) и ответы обязательно фиксируются в записи.
- В начале сессии агент **обязан прочитать** записи предыдущих ролей (особенно предшествующей
  роли текущего уровня и финальную запись предыдущего уровня), чтобы учесть принятые решения.
- Следующие роли **не должны** задавать вопросы, которые уже задавались. Свои 3 вопроса —
  всегда свои.

## Шаблон

Копируй `records/_template.md` в папку своего уровня и заполняй.
