## 🎯 Работа, выполненная в сессии

### 1. Модульная структура (по требованию пользователя)
- Исполняемый файл — **`index.html`** (точка входа, подключение модулей).
- Игра разбита на модули:
  - `css/style.css` — весь UI-оформление (дизайн-система)
  - `js/engine.js` — движок боя (вынесен из HTML без изменений логики; UMD-обёртка:
    работает в браузере как `window.Engine` и в Node через `require` для симуляций баланса)
  - `js/battle-render.js` — вся отрисовка боя на canvas
  - `js/game.js` — логика игры и UI-слой
  - `js/audio.js` — аудио-слой: заглушка с согласованным API (для Звукового дизайнера)
- Старый монолит `game-4.html` удалён. README обновлён (структура, правило пересбора по модулям).

### 2. Тотальный пересбор визуала до бара 4/10
**Юниты (canvas, «живые фигурки»):**
- Детализированные тела: градиент брони, ноги, пояс, плечи, голова с кожей
- **Эпохальные головные уборы** для всех 6 эпох: волосы+перо (камень) → шлем с гребнем (античность) →
  конический шлем (раннее ср.) → гранд-хельм (высокое ср.) → кивер (порох и пар) → визор+антенна (будущее)
- Оружие по ролям с замахом при атаке: копьё+щит, меч, лук, бомбарда, посох с пульсирующей сферой, кинжалы
- Анимации: покачивание, походка (шагающие ноги), замах оружия при ударе, вспышка при получении урона,
  затухание тел погибших, аура босса, индикаторы состояний (щит-баббл, звёзды оглушения, пламя ярости, «!» агро)
- Полосы HP с градиентом и блеском, имена боссов

**Фоны эпох (яркая казуальная палитра, анимированные):**
- Камень: закат, горы, угольки костра · Античность: море-небо, солнце с сиянием, плывущие облака, колонны
- Раннее ср.: зелёные холмы, туман · Высокое ср.: замки, падающие листья
- Порох и пар: дымка, искры · Будущее: неоновая сетка на земле, огни города, парящие частицы

**Эффекты боя:** всплывающие числа урона (крит крупнее и оранжевый), лечение, трассеры атак со
снарядом, вспышки способностей, взрывы-кольца, рывок разведчика, призывы, имена способностей.

**UI (тёмный современный):**
- Полный рестайлинг: дизайн-токены, панели, кнопки (золотой primary), чипы шапки, карточки с иконками
- **SVG-иконки всех 6 ролей** (щит, меч, лук, бомба, посох, кинжалы) — в слотах расстановки, карточках, магазине
- Иконки эпох (эмодзи) в ленте меню, шапке, эволюции; иконки артефактов
- Меню: градиентный заголовок, лента 6 эпох, панель «как играть», футер эксперимента
- Анимации появления экранов, тосты, состояния кнопок, адаптив для мобильных
- Оверлеи: эволюция армии (список форм), выбор артефакта, экраны победы/поражения со статистикой

## 📌 Заметки для следующих ролей

- **Балансиру (сессия 3/4):** движок теперь отдельный модуль `js/engine.js` — подключается в Node
  `require('./js/engine.js')` для симуляций (харнесс: наём приоритетной роли + прокачка слабых, 3 попытки;
  цель: проходимость этапов ~80–95%, боссы ~60–90%, бот ~25–35%). Числа: `STAGES`/`BOSSES`/`ROLES`/
  `TIER_MULT`/`LVL_MULT` в engine.js; экономика (`recruitCost`, `upgradeCost`, `stageReward`) — в game.js.
- **Звуковому дизайнеру (сессия 4/4):** звука нет, но есть готовый слой — `js/audio.js` со списком
  событий, которые уже дёргает игра (см. комментарии в файле: ui.click/buy/error, battle.hit/crit/
  ability/boss/die/win/lose, stage.evolve/artifact/victory/defeat). Достаточно наполнить методы
  Web Audio API без внешних файлов. Canvas-анимации боя можно синхронизировать с событиями движка
  (`onEvent` в game.js), если понадобятся визуальные акценты под звук.
