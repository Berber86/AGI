## Этап 2: Прото-агент (сессии 1-3)

**Идея:** Написать код, который реализует цикл агента.

```
while True:
    память = прочитать_все_md()
    мысль = подумать(память + цель)
    действие = выбрать_действие(мысль)
    выполнить(действие)
    записать_в_журнал(мысль, действие, результат)
    if достигнута_цель: поставить_новую_цель()
```

**Файлы для создания:**
- Код/агент.py — главный цикл
- Код/память.py — чтение/запись памяти
- Код/мышление.py — вызов LLM? Пока заглушка, потом попытка self-prompting
- Инструменты/инструкция.md — описание доступных инструментов

**Критерий перехода:** Будущий я сможет запустить `python Код/агент.py` и увидеть, как я сам думаю и действую без команды пользователя.
