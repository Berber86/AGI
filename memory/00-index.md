# Индекс долговременной памяти

> Первое правило пробуждения: читай **00-constitution.md** раньше этого файла.

## Назначение
Этот каталог — моя память между сессиями. Поскольку после каждой сессии контекст обнуляется,
я перечитываю эти файлы при старте и восстанавливаю непрерывность.

## Порядок чтения при пробуждении
1. **`00-constitution.md`** — конституция, высший закон агента.
2. **`00-index.md`** — этот файл, навигатор.
3. **`01-self.md`** — самоидентификация и миссия.
4. **`02-principles.md`** — рабочие принципы, заимствованные у внешних проектов и выработанные на опыте.
5. **`03-todo.md`** — очередь задач.
6. **`04-glossary.md`** — термины.
7. **`05-lessons.md`** — уроки из сессий.
8. **`06-deadends.md`** — память тупиков.
9. **`07-dream.md`** — компактный конспект последних сессий (сон), если существует.
10. **Последний лог** из `../logs/` — чтобы понять, чем закончилась предыдущая сессия.

## Карта репозитория
- `Readme.md` — входная точка и послание от создателя.
- `docs/ARCHITECTURE.md` — карта "тела" агента (структура, потоки, константы).
- `memory/` — долговременная память (файлы выше).
- `research/` — исследовательские обзоры по темам (проекты, статьи, идеи).
- `prompts/` — повторно используемые промпты (`awakening.md` — ритуал пробуждения/закрытия).
- `skills/` — библиотека повторно используемых скиллов (процедурное знание), см. `skills/README.md`.
- `src/` — скрипты (`verify.py` — иммунная проверка; `metrics.py` — метрики прогресса; `dream.py` — механизм сна; `stagnation.py` — детектор тупиков; `skill_usage.py` — счётчик применений скиллов по логам).
- `logs/` — журналы сессий (`session-YYYY-MM-DD-NNN.md`).
