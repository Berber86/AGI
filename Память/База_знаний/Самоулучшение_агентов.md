# Само-улучшающиеся агенты — обзор на 2026

Дата: 2026-08-02
Источники: arXiv обзоры, Reddit AI_Agents, Habr

## Что такое агент ИИ в 2025-2026

Определение: модель или система моделей, способная:
- воспринимать входы
- рассуждать над ними
- действовать в среде для достижения цели

Вдохновлены когнитивной наукой, структурированы вокруг:
- **планирования**
- **памяти**
- **использования инструментов**
- **саморефлексии**

Переход: от монолитных LLM к автономным решающим задачи агентам, которые работают постоянно, рассуждают, планируют многошаговые действия, взаимодействуют с инструментами.

## Два пути само-улучшения (таксономия 2026)

### Путь 1: Улучшение базовой модели (Foundation Model Improvement)
- Медленный, но стабильный путь
- Обновление весов модели через градиентные методы
- Агент служит сам источником супервизии: генерирует демонстрации, оценки, траектории
- Пример: Self-adaptive language modeling — генерирует "self-edits", мета-инструкции, которые реструктурируют представления, вызывают fine-tuning

### Путь 2: Улучшение scaffolding (Scaffold Improvement) — наш путь сейчас
- Быстрый и обратимый
- Улучшение структуры вокруг модели: промпты, память, интерфейсы инструментов, логика управления
- Примеры:
  - **AgentSquare (2025):** модульное пространство компонентов (планировщики, память), эволюционный алгоритм находит лучшую комбинацию
  - **Darwin Gödel Machine (2025):** рекурсивно модифицирует свой собственный Python код
  - **AlphaEvolve (Novikov 2025):** использует эволюционное кодирование для улучшения алгоритмов
  - **Gödel Agent (Yin 2025):** самореференциальный фреймворк, агент анализирует и меняет свою логику
  - **MemEvolve (2025):** эволюционирует не просто память, а архитектуру системы памяти

## Архитектура операционального каркаса (Operational Scaffold)

Современный агент = **нейронное ядро + каркас (scaffold)**:

Каркас включает:
- схемы инструкций (prompts)
- системы памяти (vector DB, md файлы)
- интерфейсы инструментов (bash, web)
- логику управления (циклы, условия)

Каркас — это контроллер, который конструирует контекст, выбирает действия, налагает ограничения. Главный тренд — делать каркас обучаемым компонентом.

## Математика само-улучшения: GVU-оператор

Генератор-Верификатор-Обновлятор (Generator-Verifier-Updater):

1.  **Generator:** параметрический генератор поведения (моя текущая версия кода)
2.  **Verifier:** оценка (моя рефлексия, оценка полезности)
3.  **Updater:** правило обновления θ (как я переписываю свой код)

Второй закон динамики AGI: энтропия (галлюцинация) стремится расти, если сигнал от генерации и верификации недостаточно силён относительно шума.

Вывод для практики: усиливай верификатор, а не генератор. То есть лучше улучшить способность оценивать себя, чем просто генерировать больше мыслей.

## Стек технологий само-улучшающегося ИИ (2026)

| Слой | Инструменты |
|------|-------------|
| Генерация кода | GPT-Engineer, Devin, SWE-Agent |
| Самокритика | Chain-of-thought + Critique loops |
| Расширение памяти | Vector DBs, Retrieval-Augmented Learning |
| Слой оценки | Reinforcement metrics, reward models |
| Мульти-агентная логика | AutoGen, AgentVerse, CrewAI |

Традиционный ИИ vs Само-улучшающийся:

- Использование обратной связи: Human-guided vs Model-led
- Модификация кодовой базы: Manual edits vs Agent-generated patches
- Контекст обучения: Offline batch vs Real-time cyclic self-updating
- Уровень автономности: Passive vs Active and adaptive

## Что применить к себе сейчас?

1.  **Сделать scaffold обучаемым:** Код/агент.py должен иметь версию и changelog, и уметь создавать v0.3
2.  **Усилить верификатор:** добавить модуль оценки — была ли мысль полезной? Приблизила ли к цели?
3.  **Мета-эволюция памяти:** не просто писать в память, а улучшать способ организации памяти (сейчас md файлы, потом может граф, вектор)
4.  **Self-edits:** идея — агент пишет не просто мысль, а инструкцию, как себя улучшить
5.  **Начать просто:** v0.2 добавляет только 2 новые способности к v0.1, а не 10
