## Следующий шаг

Запустить **сессию 3 уровня 4/10**: **Балансир** пересобирает баланс и экономику всей игры
до бара 4/10 и отвечает за чистоту кода и целостность реализации. Числа живут в `js/engine.js`
(`STAGES`, `BOSSES`, `ROLES`, `TIER_MULT`, `LVL_MULT`) и в экономике `js/game.js`.
Для симуляций баланса движок подключается из Node: `require('./js/engine.js')`.

## История изменений

- **(структура)** Игра переведена на модульную структуру по требованию пользователя:
  исполняемый файл — **`index.html`**, код разбит на `css/style.css`, `js/engine.js` (движок, чистый),
  `js/battle-render.js` (отрисовка), `js/game.js` (UI), `js/audio.js` (заглушка звука).
  Старый монолит `game-4.html` удалён.
- **(графика)** Сессия 2/4 — Графический дизайнер — сдана: тотальный пересбор всего визуала до 4/10.
  Решения пользователя: живые анимированные фигурки, яркая казуальная палитра, тёмный современный UI.
  Живые юниты (походка, замахи оружия, вспышки ударов, затухание смертей), эпохальные пейзажи с
  анимацией (угольки, облака, туман, листья, искры, неоновая сетка), SVG-иконки ролей, полный рестайлинг UI.
- **(старт 4/10 по решению пользователя)** Эксперимент стартует сразу с **уровня 4/10** (уровень 3 пропущен).
  Сессия 1/4 — Геймдизайнер — сдана: создана игра **«ЭПОХИ»**: 6 эпох, 3 акта, 12 этапов,
  эволюция армии, магазин, артефакты, 3 попытки на этап, 3 босса. Баланс прогнан симуляциями (бот ~27–31% побед).
- **(рестарт)** Удалены все игровые файлы и журналы прежних уровней. Эксперимент начинается
  заново с уровня **3/10** по накопительной команде из 3 ролей.
- **(уточнение модели)** Введён принцип **тотального пересбора**: каждая роль пересобирает всю
  свою область до производственного бара `N/10`. Шкала продакшена: 1/10 ≈ детская браузерка → 10/10 ≈ AAA.
