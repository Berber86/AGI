## Следующий шаг

Запустить **сессию №2 уровня 4/10**: роль — **Графический дизайнер (L04)**.
- **Этап А (Старт роли):** Спроектировать тотальный пересбор визуального оформления уровня 4/10 (арт-дирекшн тактического стола, стилизация формаций и эффектов).
- **Этап Б (Старт программиста для роли):** Реализовать визуальные улучшения в модулях `css/style.css` и `js/ui.js`.
- **Этап В (Старт Критика):** Оценить весь проект целиком, выявить 3 главные проблемы игры и задать пользователю 3 вопроса (для каждого варианты A, B, C + D: «Оставить так»).
- **Этап Г (Коррективы программиста):** Внести исправления по ответам пользователя, запустить автоматические тесты и сдать сессию №2.
