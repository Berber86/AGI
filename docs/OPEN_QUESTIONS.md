# Открытые вопросы (требуют решения владельца)

Вопросы, которые НЕ блокируют разработку (решения по умолчанию приняты и
задокументированы в DECISIONS.md), но могут изменить курс.

## Q-01. Имя репозитория
Репозиторий называется `AGI`, проект — «Механизм Цивилизации (Cog Empires)».
Переименовать репозиторий в `cog-empires`? (URL Pages изменится автоматически.)

## Q-02. Сохранения: только локальные?
Сейчас localStorage. Для Фазы 4 (статистика, достижения) может понадобиться
облачное хранение — это первый шаг к бэкенду. Когда открывать?

## Q-03. Пошаговость экономики: «день» тикает только от узлов
Доход начисляется при переходе по узлам кампании (привал = 2 дня). Альтернатива —
свободный тик по кнопке «Конец хода». Текущая схема держит темп кампании;
менять ли на свободную экономику?

## Q-04. Ничья в бою
Сейчас ничья = узел не пройден, добычи нет, попытку можно повторить.
Считать ли ничью поражением? Вводить ли тай-брейк (например, по % суммарных HP)?

## Q-05. Тон сеттинга
Emoji-плейсхолдеры нейтральны: стимпанк-«механизм» или фэнтези? Тексты сейчас
смешанные («шестерёнки» + «рыцари/личи»). К Фазе 1 (арт карточек) стоит определиться.
