# Команды и роли — Уровни сложности 4–10

Здесь описаны команды и глобальный реестр ролей.
Эксперимент **стартует с уровня 4/10 со всем хардкором**.

## ⚠️ Модульность и 4-этапный цикл каждой сессии

1. **Модульная структура:** игра строится на отдельных файлах (`index.html`, `css/style.css`, модули `js/*.js`), а не в одном монолите.
2. **4-этапный цикл сессии (А / Б / В / Г):**
   - **А) Старт роли:** проектирование в зоне компетенции роли.
   - **Б) Старт программиста:** первоначальная реализация кода роли.
   - **В) Старт Критика:** оценка **всего проекта целиком**, выявление 3 проблем и постановка пользователю 3 вопросов (для каждой проблемы варианты A, B, C + D «Оставить так»).
   - **Г) Программист вносит коррективы:** финальные исправления по ответам на вопросы Критика, автотесты и сдача сессии.

## Реестр ролей (глобальный порядок)

| # | Роль | Зона компетенции | Примерные темы для работы роли |
