# Журнал Архитектурных и Геймдизайнерских Решений (DECISIONS.md)

| DEC-003 | 2026-09-22 | Звуковое оформление (Audio FX) | Использование Web Audio API (синтез звуковых волн) вместо внешних mp3-файлов. | Гарантирует автономную работу без битых ссылок на ассеты, нулевой вес бандла и мгновенный отклик при ударах, критах и победе. |
| DEC-004 | 2026-09-22 | Карточный визуал UnitCard | Верстка стилизована под классические карты ККИ (Берсерк/MTG): градиентная рамка по редкости, динамические плашки статов, сгенерированный блок пассивных способностей. | Соответствует визуальному требованию Фазы 1, повышает читаемость боя и удовольствие от кастомизации. |
| DEC-005 | 2026-09-22 | Тактические карты Моментума (Momentum) | Ресурс Боевого Духа (Morale / Momentum) накапливается за удары и раунды; игрок может раз в 2-3 раунда сыграть карточку тактики. | Устраняет пассивность "чистого автобоя", позволяя игроку влиять на исход ключевых моментов. |
