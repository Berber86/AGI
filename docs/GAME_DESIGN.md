# Первичный океан — дизайн-документ

Документ описывает механики, формулы и баланс. Все числа живут в `js/config.js`,
`js/parts.js`, `js/species.js` — здесь объясняется, почему они такие.

---

## 1. Ядро цикла

1. **Ешь** биомассу или живых существ → растёт биомасса и накапливается ДНК.
2. **Растёшь** → каждый новый размер даёт здоровье, обзор и **ячейку генома**.
3. **Мутируешь** у гнезда → меняешь способности, диету, защиту, движение.
4. **Договариваешься** (танец, кормление) → получаешь союзников и безопасные зоны.
5. **Переживаешь события** → ДНК, цели, иногда угрозы.
6. **Собираешь три древних гена** → Левиафан → победа (или перенос генов в гнездо).

Провал (гибель) не отменяет прогресс вида: достижения, бестиарий и глобальная ДНК
остаются, внутри одной сессии можно возродиться в гнезде с потерей части ДНК
(25% → 35% → 45% — цена за каждую следующую смерть в одной жизни).

## 2. Клетка игрока

| Параметр | Формула | Комментарий |
|---|---|---|
| Размер (радиус) | `17 + 2.6·(уровень−1)` | уровень 1…10 |
| Здоровье | `(96 + 13·(уровень−1)) · множители + бонусы` | множители от цитоплазмы и родословной |
| Скорость | `134 · (1 − 0.018·(уровень−1)) · множители` | крупная клетка чуть медленнее |
| Энергия | `105 + 6·(уровень−1) + бонусы` | расходуется на органеллы постоянно |
| Обмен веществ | `0.32 + Σ(0.055·ур² + 0.1·ур)·множитель` | 0.7/с на старте, 2.7/с с полным геномом |
| Регенерация вне боя | `1.6/с + бонусы` | через 6.5 с без урона |
| Голод | `2.6` урона/с при нуле энергии | «не жрёшь — умираешь» |
| Рывок | 13 энергии, 2.6 с, 0.24 с неуязвимости | сила зависит от сифона/гидроскелета |

**Рост.** Биомасса на переход: `19, 35, 56, 80, 110, 147, 189, 237, 291`.
Замер ботом-эвристикой (`tests/balance.mjs`, шесть минут на жизнь, все сложности и
родословные): 5-й размер обычно на 1–4 минуте, 10-й — на 3–8. Быстрее всех охотник
(мясо дороже), медленнее — собиратель и симбионт, которым нужен фильтр. Разброс в
полтора-два раза — нормальная цена честной симуляции: бот не уходит из-под контактного
яда и не собирает пищу галсами, как человек, так что таблица годится для сравнения прогонов
между собой, а не как абсолютный секундомер.
Пищевая ценность умножается на диету клетки:

* растительная пища: `×(1 + фильтр) × родословная` (базовая ценность планктона 1.25,
  водорослевого комка — 2.0);
* мясо: `×(1 + вакуоль) × родословная`;
* `eatAll` (вакуоль 3 уровня) снимает штрафы и берёт лучший из множителей.

Таким образом, **всеядность — это апгрейд**, а не стартовое состояние.

**Управление (стик).** Палец в любой точке левой части экрана (58% ширины, вся высота)
задаёт вектор тяги: ось нормируется по радиусу хода (`60` ед.), внутри мёртвой зоны `14%`
не даёт команд вовсе, дальше — кривая `^1.3` (мелкие подправки точные, полный ход —
резкий). Чувствительность выбирается в настройках: «Плавно / Обычно / Резко» —
82/60/44 единицы полного хода. Подложка стика появляется **в точке касания** и по размеру
равна «полный ход + радиус шайбы» (при «Обычно» — 160 px), внутри неё пунктиром нарисована
мёртвая зона, а шайба едет точно под пальцем и на полном отклонении встаёт у края подложки,
не вылезая наружу.

**Почему клетку «тянет».** Четыре силы, все — намеренные:

| Сила | Когда | Ощущение |
|---|---|---|
| Притяжение пищи | всегда, если есть фильтр/реснички/люциферин | еда сама летит к мембране (видна струйка) |
| Отдача от толчка | столкновение с клеткой не меньше 85% вашего радиуса | отбрасывает; масса и плавники гасят до −80% |
| Течение прилива | событие «Приливный шторм» | весь океан тянет к центру |
| Замедление | чернила сепиолы, споры микото, биссусовые нити | скорость и поворот падают |

Радиус притяжения пищи: `min(210, 62 + органеллы + 2.5·уровень)` (на первом размере — 65 ед.,
это 16% ширины телефона; с фильтром 3 и ресничками 3 — 171 ед.). Еда, которую уже тянет,
помечается `pulledAt` и рисует светлую струйку — так «магнитики» читаются как механика,
а не как баг. Подробный ответ на вопрос «почему тянет» есть в справке игры.

**Ячейки генома.** `6 + 1.2·(уровень−1)` → 6 ячеек на старте, 16 на десятом размере.
Каждая деталь стоит 1 ячейку (кроме цитоплазмы — она «бесплатная», но требует обмена
веществ). Это главный ограничитель сборки.

## 3. Органеллы

22 детали в четырёх вкладках, до 5 уровней. Полный список — в `js/parts.js`;
ключевые неочевидные эффекты:

| Деталь | Роль |
|---|---|
| Цитоплазма | +здоровье, +регенерация, −скорость; 5 уровней, 0 ячеек |
| Хитиновая мантия | +броня, −скорость, +масса (толкают хуже) |
| Шипы | контактный урон + отбрасывание; уровень 3 пробивает броню |
| Скользкая мембрана | броня + регенерация, устойчивость к замедлению |
| Гидроскелет | сила рывка и скорость |
| Фильтр | ценность растительной пищи (+70/+130/+210%) + притяжение |
| Вакуоль | ценность мяса + ДНК; 3-й уровень — всеядность |
| Митохондрии | запас и восстановление энергии (топливо для всего) |
| Литические ферменты | +% ДНК со всего съеденного, скорость укуса, вампиризм |
| Токсины | яд при укусе; со 2-го уровня — способность «Ядовитое облако» |
| Биссусовые нити | замедление жертвы, отбрасывание |
| Жгутик | скорость (+второй хвост с 3 уровня) |
| Реснички | управляемость + притяжение мелочи |
| Плавники | скорость, поворот, устойчивость к толчкам |
| Реактивный сифон | дальний рывок, меньше перезарядка; 2-й уровень — «Реактивный рывок» |
| Жабровые пластины | дешевле обмен веществ, восстановление энергии, ночное зрение |
| Глазное пятно | обзор + радиус радара; 3-й уровень — ночное зрение |
| Симбионты | энергия, здоровье, регенерация; визуально кружат вокруг клетки |
| Люциферин | свечение, притяжение планктона, ночное зрение, приманка мелочи |
| Хроматофоры | невидимость после удара; 2-й уровень — способность «Мираж» |
| Звуковой орган | обзор + «Ультразвук» (оглушение по площади) |
| Электроциты | «Электрошок», пробитие брони, контактный урон |

Активная способность выбирается по приоритету
`электрошок → ультразвук → реактивный рывок → яд → мираж`: одна кнопка, разные сборки.

Мутация вне гнезда стоит +25%. Убрать деталь можно, вернув 60% вложенной ДНК —
ошибки не наказываются смертельно.

## 4. Диета и родословные

| Родословная | Стиль | Старт |
|---|---|---|
| Собиратель | быстро растёт на растительной пище, дешёвый обмен веществ не нужен | фильтр + реснички, +20 ДНК |
| Охотник | мясо ×1.45, обмен веществ −15%, крепче | челюсти + жгутик, +20 ДНК |
| Всеядный | без штрафов, +25% репутации | ротовой диск + вакуоль, +30 ДНК |
| Симбионт | энергия от симбионтов, скидка на зов стаи | симбионты + глазки, +24 ДНК (открывается достижением) |

Сложности (Лужа / Океан / Разлом / Бездна) масштабируют урон среды (0.7…1.6),
здоровье существ (0.85…1.4), обилие пищи (1.45…0.6), плотность (0.72…1.5),
агрессивность спавна (0.65…1.7) и доход ДНК (1.25…0.8).

## 5. Экосистема

* **Плотность** поддерживается по целям: база 58 существ × множитель сложности ×
  множитель события × функция угрозы `0.7 + 0.05·уровень_угрозы` (0.6…1.6).
* **Уровень угрозы** растёт от размера игрока и времени: `1 + 0.86·(уровень−1) + t/320`.
* **Спавн** — от 520 до 1250 единиц от игрока (дальше — спокойнее), деспавн на 1500.
* **Ниши**: пассивные фильтраторы, стайные травоядные, всеядные-оппортунисты,
  хищники-преследователи, засадники, падальщики, охранники территорий, босс.
* **Пищевые цепи**: существа едят биомассу и друг друга, оставляют куски плоти;
  падальщики приходят первыми, хищники — за ними.
* **Реакция на игрока**: репутация вида меняет агрессию, укус вызывает побег или месть
  (`hurtAt` → 3 секунды страха), крупный игрок пугает мелких, стайные зовут соседей.

Роли описаны в `js/ai.js`: `updatePeaceful`, `updateHunter`, `updateBoss`, `updateAlly`.
Существа «думают» раз в 0.22–0.47 с (нагрузка снижена), движутся через steer с
разделением от соседей, у крупных хищников есть способности (`ink`, `stun`, `slam`,
стрельба крапивными капсулами у стрекача).

## 6. Репутация, танец, союзники

* Танец: остановиться рядом с существом и не кусать. Прогресс +0.42/с (медленнее,
  если существо крупнее игрока на 2+ уровня). Завершение даёт +6.6 репутации и
  +1 синхронизацию (до 3 — награды за повторные танцы с видом).
* Убийство: −7 репутации, но −11 при убийстве «своего» вида (множитель 1.6)
  и +6.6 при кормлении рядом с другим видом.
* Порог дружбы: +62 → вид больше не нападает и даёт союзников по зову.
  Порог вражды: −45 → вид охотится на игрока при любой возможности.
* Зов стаи: 18 ДНК, 22 с перезарядки, 2…4 союзника на 26+ с; у вида должно быть ≥62
  репутации. Союзники следуют за игроком и атакуют врагов.

## 7. События

| Событие | Что делает | Цель |
|---|---|---|
| Цветение планктона | ×1.6 еды, приток травоядных, поток частиц 22/с | съесть 24 частицы |
| Приливный шторм | течение к центру, искры, гибнет мелочь | пережить 16 с вне гнезда |
| Великая миграция | косяк до 22 особей идёт через океан | убить 5 |
| Охота началась | крупный хищник вечно знает, где игрок | убить преследователя |
| Падёж гиганта | 16 кусков падали, сбегаются падальщики | съесть 6 кусков |
| Споровое облако | 7 движущихся облаков с уроном | продержаться 26 с вне спор |
| Левиафан пробудился | босс с тремя фазами | убить или донести гены |

События идут с интервалами 36–74 с, не повторяются подряд, во время финала не
запускаются. Каждое даёт ДНК за цель и меняет модификаторы мира (`foodMul`, `popMul`).

## 8. Бой

* Кусать можно любую цель в конусе ~86° перед клеткой, радиус = сумма радиусов + 22.
* Проглотить начисто можно существо, у которого `радиус·1.22 < радиус игрока`
  **и** здоровье меньше 90% радиуса игрока — иначе укус наносит урон.
* Урон по игроку: контактный (0.3–0.55 базового урона × 1.4), укус агрессора (0.75),
  яд, снаряды, аура босса. Броня снижает урон по формуле `1/(1 + броня/34)`.
* Шипы игрока бьют каждого, кто врезался (0.5 с на цель), с отбрасыванием.
* Левиафан: фаза 1 — притяжение (210 ед/с к себе), фаза 2 — токсичная аура и призыв
  миньонов, фаза 3 — таранный разрыв с уроном и отлётом. Здоровье — 6.5× базового.

## 9. Мир и время

* Радиус океана 3400 единиц, «плёнка поверхностного натяжения» по краю: за границу не
  выпускает, при попытке — предупреждение.
* Сутки — 200 с, старт утром. Свет `0.16 + кривая_суток · 0.86 · свет_биома`
  (Мелководье 1 → Бездна 0.2). Ночью дальность видимости существ падает,
  если нет ночного зеленья.
* Биомы: Мелководье (0–28% радиуса), Риф (28–56%), Разлом (56–80%), Бездна (80–100%).
* Объекты: гнездо (центр), камни, рифы, вентиляторы (урон при контакте), обломки
  (клады ДНК), реликтовые поля (выращивают древний ген раз в ~60–100 с и призывают
  стрекача-стражника).

## 10. Прогресс между жизнями

* 23 достижения дают глобальную ДНК и открывают: хитиновую мантию, гидроскелет,
  звуковой орган, электроциты, родословную «Симбионт».
* Наследие вида: «Богатая спора» (+15 стартовой ДНК за уровень, 3 уровня) и
  «Плотная оболочка» (+12 здоровья, 3 уровня) — покупается глобальной ДНК.
* Бестиарий: 20 видов с лором; встреча с видом открывает запись навсегда.
* Итог жизни фиксирует размер, убийства, время, танцы, союзников и реликтовые гены.

## 11. Производительность

* Симуляция: пространственный хеш (две сетки — существа и еда), «мышление» существ
  раз в 0.22–0.47 с, прореживание проверок «хищничества» между NPC, кэш пулов частиц.
* Отрисовка: `devicePixelRatio` ограничен качеством, параллакс из 150 частиц,
  каустика — только в светлых биомах и по качеству, двойная буферизация в один canvas.
* Замер в безголовом тесте: **0.26 мс на кадр симуляции** на Node при ~60 существах
  и 240 частицах биомассы; в мобильном Chromium с программным GL — 18 мс/кадр.
* Автоснижение качества: если средний кадр за 90 кадров хуже 33 мс, качество
  переключается с «Богато» на «Обычно».

## 12. Идеи для следующей итерации

1. Племена существ (группы с вождём, территорией и «дипломатией» между видами).
2. Генетические «мутации-артефакты»: редкие детали из реликтовых полей.
3. Сезонные течения: медленно движущиеся потоки, влияющие на маршруты стай.
4. Аквариум-режим: посадить любимый вид и наблюдать за эволюцией без игрока.
5. Экспорт генома в виде ссылки-строки, чтобы делиться сборками клеток.
