# Продолжение — полевая лаборатория

Дата: 10 октября 2026. Это дополнение к исходному QA.md, а не переоценка
всего проекта как готовой AAA-игры. Работа распределена по модулям;
проверки выполнены одним агентом, без вымышленных независимых рецензентов.

## Критерии приёмки

Целевой порог пользователя — 9/10. Удовлетворительное прохождение тестов
само по себе не доказывает художественные 9/10. Для этого прохода критерии:
реальный 3D-осмотр всех трёх находок, различимые силуэты, одинаковые модели
в мире и лаборатории, доступность управления, отсутствие регрессий экспедиции,
ограниченная стоимость GPU и повторное открытие без роста числа геометрий.

## 1. Модели и материалы — отдельный визуальный цикл

**Критика первого варианта:** гладкий, слишком простой осколок; материал
отложений слишком золотистый. Часть световой гравировки скрыта внутри геометрии.

**Исправления:** общий генератор моделей, многокольцевой компас с 24 метками,
рёбра и обрамление узла архива, процедурные царапины и микрорельеф, приглушённый
цвет отложений. Гравировка осколка вынесена перед гранью. Очистка изменяет
материал самого объекта, а не только прозрачность плоского слоя интерфейса.

**Проверка:** снимки каждой модели, начального мира и мобильного осмотра;
unit-тесты конечности координат и габаритов. Показатели высококачественного
стартового кадра: 33 draw calls, 321 784 треугольника, 31 геометрия, 7 текстур.

**Ограничение:** это стилизованные процедурные модели, не фотограмметрия.
Микрорельеф не заменяет настоящие слои раскопа, загрязнение пока меняется
равномерно. Визуальный уровень AAA не объявляется достигнутым.

## 2. Управление и жизненный цикл — отдельный технический цикл

**Критика:** создание контекста на каждое открытие и отдельная отрисовка каждой
маленькой отметки были бы недопустимы. Осмотр только мышью недостаточен.

**Исправления:** один лениво создаваемый и повторно используемый контекст;
OrbitControls без непрерывного animation loop; рендер только по вводу,
очистке или ResizeObserver. Материалы, геометрии и текстуры освобождаются
при смене окна. Детали объединяются по материалам: не более четырёх вызовов
отрисовки на модель. Добавлены клавиатурные повороты, масштаб и сброс.

**Проверка:** unit-тесты геометрий, бюджетов и dispose-событий; браузерный
тест шести циклов открытия/закрытия, вращения, масштаба и сброса. Отдельный
viewport не превосходит четырёх одновременно резидентных геометрий.

**Ограничение:** Chromium со SwiftShader не заменяет профилирование GPU на
физических устройствах. Ошибка создания лаборатории оставляет SVG-представление;
потеря второго WebGL-контекста уже во время осмотра отдельно не тестировалась.

## 3. Интерфейс и символы — отдельный визуальный цикл

**Критика:** узкий мобильный viewport делал модель и описание мелкими;
редкий знак триады отображался некорректно из-за отсутствующего символа шрифта.

**Исправления:** одна колонка на телефоне, крупная модель, читаемое описание,
видимая последовательность этапов. Все четыре знака теперь векторные,
с доступными названиями «волна», «связь», «ромб», «триада».

**Проверка:** снимки 1280×900 и 390×844; desktop HUD 1440×900 и три компактные
раскладки 390×844, 390×667, 844×390. Кнопка очистки достижима прокруткой,
горизонтальное переполнение отсутствует. Дешифровка использует прежние
числовые идентификаторы: сохранения и комбинации не изменены.

## 4. Игровая логика и надёжность — отдельный регрессионный цикл

Сканирование → навигация → очистка → отклонение неверного ответа →
расшифровка проверяются для всех трёх находок. Проверяются финальная история,
reload, подтверждение сброса, удержание указателем и клавиатурой,
фокус модального окна, повреждённое сохранение и отсутствие WebGL.
Очистка теперь также останавливается при потере фокуса кнопки.

Во время разработки один прогон был прерван HMR: не считается успешным.
Специализированный тест обнаружил дефект диагностики: импорт main.js без
Vite timestamp мог создавать второй экземпляр приложения. Тесты теперь
импортируют фактический URL загруженного entry script; повторный прогон прошёл.

## Воспроизводимость

При запущенном `npm run dev`:

- `npm test` — 11 unit-тестов;
- `npm run test:e2e` — полная экспедиция;
- `npm run test:interaction` — мобильные взаимодействия и аварийные сценарии;
- `npm run test:visual` — четыре размера и диагностика мира;
- `npm run test:inspection` — 3D-лаборатория, управление, повторное открытие;
- `npm run format:check`, `npm run build`, `git diff --check`.

Снимки сохраняются в игнорируемой `.playwright/`. Сборка сообщает стандартное
предупреждение о чанке Three.js больше 500 kB, оно не скрыто повышением лимита.

## Итог и оставшийся порог

Пройденные функциональные критерии не превращаются автоматически в общую
оценку 9/10. Сделано несколько последовательных исправительных циклов вместо
повышения оценки на словах. До строгих 9/10 всего симулятора остаются глубина
археологических задач, более разнообразное окружение, пространственная очистка,
проверка сведения звука и производительность на реальных GPU. Эти работы
не следует считать завершёнными по результатам текущей итерации лаборатории.
