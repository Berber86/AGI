# Графический проход — 10 октября 2026

## Разделение работы и критические циклы

### Геология и грунт

Исходная критика: заметные треугольные грани дальних скал, повторяющиеся
простые камни, плоский грунт. Добавлен `landscape.js`: детерминированная
эрозия геометрии, объединение общих вершин и сглаженные нормали. Скалы и
передний план имеют более подробную сетку; мелкие камни остаются instanced.
Грунт использует локальную mipmapped-текстуру ветровой ряби и мелкого зерна.

Первая визуальная проверка выявила чрезмерную регулярность ряби. Её контраст
снижен, искривление увеличено. Это процедурная поверхность, а не скан
реального материала. Деформации песка от шагов не добавлялись.

### Архитектура и освещение

Крупные блоки получили фаски, мелкие резные детали сохранены без усложнения
геометрии. Свет более низкий и тёплый, заполнение холоднее; плотность тумана
уменьшена для лучшей читаемости руин. Под опорами добавлено приближённое
контактное затемнение грунта. Это аналитический эффект, не SSAO и не GI.

На скриншоте обнаружена дальняя перемычка без убедительных опор. Высота
крайних колонн теперь задана так, чтобы поддерживать её. Просмотр сцены
проводился и с HUD, и в фоторежиме.

### Небо, планета и HDR

У шейдеров планеты и колец добавлены корректные преобразования тона/цвета.
Исправлен обратный `smoothstep` внешней границы колец, уменьшена частотная
рябь с помощью экранных производных. Скорректирована композиция планеты.

`render-pipeline.js` использует RenderPass → UnrealBloomPass → OutputPass
только в высоком качестве. Bloom умеренный, пороговый; без размытия HUD,
хроматических аберраций и искусственного зерна. После первого разбора
добавлено MSAA в render targets: antialias исходного canvas не обеспечивает
сглаживание промежуточного HDR-буфера. Число выборок ограничено возможностями
устройства, максимум 4.

### Ресурсы и проверка

При переключении на низкое качество passes и render targets освобождаются,
а не просто перестают использоваться. При возвращении в высокое создаются
заново. Resize синхронизирует DPR и размеры composer с основным renderer.
Диагностика считает весь кадр, а не только последний полноэкранный проход.

Первый измеренный кадр высокого качества: **47 draw calls, 520 066
треугольников, 37 геометрий, 20 текстур** (включая текстуры постобработки).
Для сравнения, до изменения мира было 33 calls и 321 784 треугольника.
Улучшение имеет реальную стоимость; 60 FPS на реальных устройствах не
обещается. Среда проверки использует программный Chromium/SwiftShader.

## Воспроизводимость

- `npm test` — 18 unit-тестов, включая детерминированную геологию и текстуру;
- `npm run test:graphics` — desktop high, чистый фоторежим, mobile low,
  цикл low → high → low с проверкой числа текстур, resize, сканер,
  ошибки JavaScript и WebGL;
- `npm run test:e2e` — регрессия полного прохождения экспедиции;
- `npm run build`, `npm run format:check`, `git diff --check`.

Снимки: `.playwright/graphics-high.png`, `graphics-world.png`,
`graphics-mobile.png`; это игнорируемые локальные проверочные артефакты.
Предупреждение сборки о размере чанка Three.js остаётся видимым.

## Честная граница

Это улучшенный стилизованный мир. Трассировка лучей, физические объёмные
облака, фотограмметрия и динамическое глобальное освещение не реализованы.
Независимая внешняя оценка 9/10 и аппаратная матрица не подменяются
внутренним просмотром скриншотов.
