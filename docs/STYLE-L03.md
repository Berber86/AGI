# Визуальный гайд — уровень 3/10

**Роль:** Графический дизайнер
**Назначение:** руководство для Программиста (реализация визуала в `game-3.html`).
Стиль по ответам пользователя: **минимализм с чёткими линиями**, **яркая подсветка рядов**,
**иконки + анимации способностей**.

---

## 1. Общий стиль: минимализм с чёткими линиями

- **Фон:** тёмный градиент по эпохе (как в прошлых версиях), но чище и сдержаннее.
- **Панели:** лёгкий полупрозрачный фон `rgba(255,255,255,.06)` с чёткой тонкой рамкой.
- **Шрифт:** системный (Segoe UI / Roboto), читаемый; крупные заголовки, компактные подписи.
- **Цвета:** минимум шума — один акцентный цвет (золотой) для действий/валюты, нейтральные
  тона для панелей. Насыщенные цвета — только для способностей и рядов (см. ниже).
- **Отступы и сетка:** равномерные поля, карточки одного размера, выравнивание по сетке.

**Палитра:**
| Роль | Цвет |
|------|------|
| Акцент/действия/золото | `#ffd97a` |
| Текст | `#f4ecd8` |
| Мутный текст | `#b9a97f` |
| Панели | `rgba(0,0,0,.28)` + рамка `rgba(255,255,255,.16)` |
| Успех/лечение | `#7ee07e` |
| Опасность/урон | `#ff7e7e` |

---

## 2. Ряды: яркая подсветка

Механика передний/задний ряд передаётся визуально (по ответу r1):

- **Передний ряд** — рамка/подложка **тёплого тона** (например, янтарная `rgba(255,180,60,.18)`)
  с рамкой `#ffb03a`. Слоты переднего ряда чуть плотнее, «бронированные».
- **Задний ряд** — рамка/подложка **прохладного тона** (например, голубая `rgba(120,180,255,.16)`)
  с рамкой `#7ec8ff`. Подчёркивает «дальний, бьющий» ряд.
- На каждом слоге заднего ряда — **значок бонуса** `+15% ⚔️`, чтобы игрок сразу видел преимущество.
- Подписи рядов: «Передний ряд» / «Задний ряд» с соответствующими цветами.

---

## 3. Способности: иконки + анимации

По ответу a3 — и иконки, и анимации срабатывания:

**Иконки способностей** (единый размер, цветной бейдж):
| Способность | Иконка | Цвет бейджа |
|-------------|--------|-------------|
| Обычный | — | серый |
| Крит | 🎯 | оранжевый `#ff7043` |
| Лечение | 💚 | зелёный `#7ee07e` |
| Блок | 🛡️ | голубой `#7ec8ff` |
| Вампиризм | 🩸 | тёмно-красный `#d44040` |
| Цепной урон | 🛰️ | фиолетовый `#ba68c8` |
| Щит | ✨ | бирюзовый `#4dd0e1` |

Иконки показываются: в лавке, на карточке армии, на юните в бою (маленький бейдж).

**Анимации срабатывания** (лёгкие, не мешают боя):
- Крит — вспышка/«свечение» наносимого урона + красное число.
- Лечение — мягкое свечение вокруг цели зелёного цвета.
- Вампиризм — небольшой красный отблеск на юните при восстановлении HP.
- Цепной урон — короткая визуальная линия/звёздочка между целью и соседями.
- Щит — полупрозрачный «пузырь» вокруг юнита в начале боя.
- Полоски HP — как раньше: зелёная у своих, красная у врагов.

---

## 4. Экраны

- **Лавка** — сетка карточек с иконкой, именем, статами, способностью и ценой.
- **Армия** — 5 слотов: 3 «передних» + 2 «задних», каждый с иконкой и бейджем способности.
- **Бой** — два столбца (свои/враги), юниты с HP-полосками и анимациями.
- **Баннер победы/поражения** — как раньше, но в минималистичной рамке.

---

## 5. Что реализует Программист

- CSS-переменные по палитре выше.
- Стили для переднего/заднего ряда + значок бонуса.
- Бейджи способностей (эмодзи + цвет) в лавке, армии и бою.
- Лёгкие CSS-анимации срабатывания способностей.
- Сохранение единого «минималистичного» вида всех панелей.
