# Итерация 02 — региональная очистка

10 октября 2026. Продолжение предыдущей итерации лаборатории. Работу
выполнял один агент, с разделением по модулям и отдельными проверочными
циклами, а не вымышленная команда независимых экспертов.

## Цель

Заменить равномерное обесцвечивание находки взаимодействием с её геометрией.
Минимальные критерии: независимость участков, попадание кисти только в модель,
видимый локальный результат, археологическая отдача, сохранение прогресса,
полноценная альтернатива для клавиатуры и отказоустойчивость лаборатории.

## 1. Механика и состояние

**Проблема:** один процент очистки не описывал, с какой частью объекта
работал игрок. Появление трёх процентов не должно ломать старые экспедиции.

**Реализация:** у каждой реликвии три значения `sectors`; общий `clean`
вычисляется как среднее. Для старого формата процент переносится во все три
участка. Новые данные участков приоритетнее устаревшего общего процента.
Невалидные значения ограничиваются или обнуляются; частично очищенную
находку нельзя расшифровать через сохранённый флаг `decoded`.

**Проверка:** отдельные unit-тесты миграции, восстановления, недопустимых
индексов/чисел, независимости участков и запрета ранней дешифровки.
Существующие тесты экспедиции сохранены.

## 2. Инструмент кисти

**Реализация:** raycast пересекает только геометрию модели; точка попадания
переводится в локальные координаты. Верх, центр и низ определяются по
габаритам конкретной находки. Кисть и OrbitControls взаимоисключаются.
Таймер активен только при удержании; длительность шага ограничена, чтобы
долгая задержка вкладки не превращалась в мгновенную очистку.

**Критический проход:** проверка прерванного мазка выявила совпадение
`data-sector` у курсора и кнопок выбора участка. Курсор переведён на отдельный
`data-hit-sector`; селекторы больше не смешивают визуальный элемент и органы
управления. Точка попадания пересчитывается на каждом шаге, даже если модель
была повёрнута клавиатурой без перемещения указателя.

**Проверка:** реальный указатель очищает верхний участок, не затрагивая
остальные; промах не даёт прогресса. Потеря фокуса окна прекращает мазок и
сохраняет частичный результат. Отдельно проверяются выбор участка и удержание
Enter. Обработчики pointercancel/lostpointercapture/visibilitychange также
останавливают кисть, но каждый из этих путей отдельно не автоматизирован.

## 3. Материал отложений

**Первый визуальный проход:** пространственный эффект работал, но ровная
горизонтальная граница напоминала покраску, а не минеральный слой.

**Исправление:** неровный переход с процедурной эрозией, зернистость, изменение
шероховатости, металличности и свечения. Маска задана в локальных координатах:
вращение объекта и камеры не переносит очищенные области. Одинаковые
uniforms используются всеми материалами реликвии, дополнительная геометрия
и проходы рендера не создаются.

**Проверка:** просмотр снимков частично очищенной модели; компиляция шейдера
в Chromium с контролем ошибок WebGL. Полная экспедиция проходит все три
модели и стадии материала. Это проверка корректности, не измерение FPS на
реальном GPU.

## 4. Археологическая отдача и интерфейс

Каждый очищенный участок открывает знак и наблюдение. Для трёх предметов
добавлено девять наблюдений: следы обработки, запись и излом; шкала,
подвес и опорная метка; оболочка, ядро и архивная печать. Наблюдения
открываются только по достижении 100% соответствующего участка.

**Критический проход:** на телефоне длинный список наблюдений оттеснял
управление. Теперь список — нативный раскрываемый блок, изначально свёрнутый
на узком экране. Переключение кисти и обзора перенесено над моделью;
кнопка сброса находится в той же строке на телефоне. В keyboard focus trap
добавлен `summary`. Элементы дешифровки получили семантический `role="img"`
для доступного чтения надписи.

## 5. Аварийный цикл лаборатории

Закрыта незавершённая проверка предыдущей итерации: потеря второго WebGL-
контекста. Лаборатория прекращает кисть, освобождает ресурсы, показывает
резервный SVG и объяснение. Экспедиция и кнопочная очистка продолжают
работать. До восстановления контекста повторное открытие остаётся в
резервном режиме; после восстановления снова доступен 3D-осмотр.

Тест вызывает `WEBGL_lose_context` именно у canvas лаборатории, проверяет
резервный вид, завершение очистки без 3D и повторное открытие после
восстановления. Это контролируемая эмуляция браузерного события, а не
испытание физического сбоя видеодрайвера.

## Воспроизводимые проверки

При работающем `npm run dev`:

- `npm test` — 16 unit-тестов;
- `npm run test:excavation` — независимая проверка новой механики;
- `npm run test:e2e` — полное прохождение, ошибочные ответы, финал, reload, reset;
- `npm run test:inspection` — три модели, управление, шесть циклов открытия;
- `npm run test:interaction` — мобильное удержание, фокус и аварийные сценарии;
- `npm run test:visual` — HUD в четырёх размерах;
- `npm run format:check`, `npm run build`, `git diff --check`.

Проверочные снимки `.playwright/excavation-regional.png` и
`.playwright/excavation-mobile.png` — локальные артефакты, не исходные ассеты.
Сборка по-прежнему предупреждает о размере чанка Three.js; лимит не повышен
для сокрытия предупреждения.

## Границы результата

Три участка — осознанное ограничение этой итерации: обработка точки очищает
крупную область, включая обратную сторону того же участка. Это не
попиксельная очистка, воксельный раскоп или симуляция хрупкости материала.
Кнопка «Все участки» оставлена доступной альтернативой точному наведению.

Вторая итерация улучшает содержательность исследования, но не доказывает
общий AAA-рейтинг 9/10. Внешняя художественная оценка, глубина дешифровки,
разнообразие мира, прослушивание звука и аппаратная матрица остаются вне
подтверждённого результата. Пройденные технические критерии не заменяются
завышенной субъективной оценкой.

### Итог повторной приёмки

Все пять браузерных сценариев (excavation, e2e, inspection, interaction,
visual) прошли после исправления конфликта селекторов. Модульные тесты:
16/16. Проверка формата, production-сборка и `git diff --check` успешны.
Показатели стартового мира не выросли: 33 draw calls, 321 784 треугольника,
31 геометрия, 7 текстур. Лабораторные модели остаются в бюджете не более
четырёх геометрий при повторных открытиях.

Дополнительная визуальная критика зерна: произведение синусов давало
регулярный узор, похожий на ткань. Оно заменено слабой модуляцией от уже
существующей процедурной карты шероховатости; новых текстур не добавлено.
После этой изолированной правки материала повторно пройден сценарий
excavation с контролем компиляции WebGL и просмотрен снимок частичной очистки.
