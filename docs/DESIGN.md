# Механизм Цивилизации (Cog Empires) — Game Design Document (GDD)

## 1. Концепция и Видение

**«Механизм Цивилизации» (Cog Empires)** — это гибридная пошаговая стратегическая игра, совмещающая макро-развитие цивилизации (Innovation / Civilization) с глубоким микро-менеджментом отрядов и автотактическим боем (Diablo / Berserk / Slay the Spire).

Игрок управляет восходящей цивилизацией пара и шестерёнок. Через исследование карточных технологий и возведение мануфактур игрок аккумулирует символы-иконки (Ремесло, Наука, Культура, Война, Горное дело, Земледелие) и открывает фундаментальные «Догмы». Главная цель цивилизации — снабжать три элитных отряда (Авангард, Дуэлянт, Арканист) легендарными шестерёнками-артефактами и провести их через опасные узлы roguelike-кампании к свержению Автоматона-Владыки.

---

## 2. Ключевые Референсы

1. **Innovation (Карл Чудик):**
   - Технологии представлены карточками, несущими набор символов (Craft, Lore, Culture, War, Mining, Agri).
   - «Догмы» — мощные постоянные правила цивилизации, активирующиеся автоматически при достижении порога определённых символов (например, ≥4 War активирует догму «Штурмовой марш»).

2. **Diablo / Path of Exile:**
   - Модульный лут с редкостями: Обычный (Common) → Редкий (Rare) → Эпический (Epic) → Легендарный (Legendary).
   - Сет-бонусы экипировки (2 и 3 предмета в сете).
   - Крафт и слияние предметов: 3 одинаковые шестерёнки объединяются в шестерёнку рангом выше.

3. **Берсерк CCG / Magic: The Gathering:**
   - Юниты как боевые карты: арт, рамка редкости, показатели атаки/защиты/скорости/дальности, блок способностей.
   - Боевой дух (Morale): критические удары поднимают боевой дух, потери снижают его. Падение боевого духа до 0 вызывает панику/отступление.

4. **Slay the Spire:**
   - Узловая ветвящаяся карта кампании (Обычный бой, Элитный страж, Кузня/Мастерская, Привал/Святилище, Босс Цикла).
   - New Game+ (Циклы): победа над боссом запускает следующий Цикл с повышенной сложностью и редким лутом.

5. **Civilization (в микро-формате):**
   - Город производит Золото, Шестерни (лом), Очки Науки и Культуры за такт.

## 3. Боевая Система

### 3.1 Поле боя и Размещение
- **Сетка:** 10 на 20 клеток. 
- По вертикали — 5 боевых линий (Линия 0..4).
- По горизонтали — 20 колонок (0..9 — зона игрока, 10..19 — зона врагов).
- **Линии размещения:**
  - **Frontline (Авангард):** ближний бой, высокая защита, провоцирует атаки врага.
  - **Midline (Дуэлянт/Фланкер):** средняя дистанция, высокий крит/уворот, фланговые выпады.
  - **Backline (Арканист/Артиллерия):** дальний бой, заклинания по площади, уязвимость вблизи.

### 3.2 Фазы Раунда
1. **Фаза Внезапной Атаки (Ambush Phase):**
   - Срабатывает до Раунда 1. Юниты с высоким показателем Скорости и специальным свойством «Ambush» наносят упреждающий удар.
2. **Основные Раунды (Initiative Rounds):**
   - Очередь хода определяется динамической инициативой (Speed + бросок кубика d20).
   - Каждый юнит совершает действие: атака, способность или применение эффекта.
3. **Расчёт Урона:**
   - `Урон = max(1, Атака * МножительКрита - Защита * КоэффициентПоглощения)`
   - Шанс попадания: `min(98%, max(10%, Точность - УклонениеЦели))`
4. **Статусы и Эффекты:**
   - **Яд (Poison):** урон в начале хода, игнорирующий броню.
   - **Оглушение (Stun):** пропуск следующего хода.
   - **Замедление (Slow):** снижение скорости на 40%.
   - **Энергетический Щит (Shield):** поглощает входящий урон до истощения зарядов.
5. **Боевой Дух (Morale):**
   - Стартует со 100%.
   - При гибели союзника падает на 25%. При крите врага падает на 10%.
   - Если дух < 20%, юнит получает штраф -30% к урону и точности.
   - При 0% юнит пытается бежать.

## 4. Экономика и Дерево Технологий

### 4.1 Ресурсы
1. **Золото (Gold):** найм, улучшения, покупка компонентов.
2. **Шестерни / Запчасти (Cog Parts):** материал для мастерской и крафта.
3. **Наука (Science):** исследование узлов технологий.
4. **Культура (Culture):** активация продвинутых гражданских догм.

### 4.2 Иконки и Догмы (Innovation Mechanics)
- Иконки: ⚙️ `Craft` (Ремесло), 📜 `Lore` (Наука/Лор), 🎭 `Culture` (Культура), ⚔️ `War` (Война), ⛏️ `Mining` (Добыча), 🌾 `Agri` (Аграрное дело).
- Каждая изученная технология добавляет иконки к пулу цивилизации.
- Пороги активируют догмы, например:
  - `Craft >= 3`: «Автоматическая подача» (+10% скорости всем отрядам).
  - `War >= 4`: «Осадная инженерия» (дальнобойные атаки игнорируют 25% брони).
  - `Lore >= 4`: «Теория цепей» (+20% к шансу крита арканиста).

---

## 5. Экипировка: Шестерни (Cogs)

У каждого из 3 юнитов есть 3 слота:
1. **Главная передача (Core Cog):** базовые урон и здоровье.
2. **Приводной механизм (Drive Cog):** скорость, точность, инициатива.
3. **Вспомогательный узел (Auxiliary Cog):** защита, крит, статусные эффекты и сетовые свойства.

Слияние (Transmutation):
- 3 шестерни одинаковой редкости объединяются в 1 шестерню следующей редкости.
- Сетовые эффекты: Steamforged (Пар), Clockwork Dragon (Дракон), Titan Guard (Титан), Void Core (Пустота).

---

## 6. Циклы и Прогрессия (Meta-game)

- Кампания состоит из 8-12 взаимосвязанных узлов на карту с боссом в конце.
- Победа над Боссом завершает Цикл, повышая множитель вражеских характеристик на 25% и улучшая качество дропа шестерёнок.
