# Сравнение двух вариантов правок 3/6/8/9/10 (01.10.2026)

На ветке `arena/01a0f2a9-agi` оказались две независимые реализации одних и тех же правок:
вариант **A** (эта сессия, коммит `32fd57d`) и вариант **B** (ранее залитый в ветку, `fb33689` + `9be10d4`).

Метод: обе версии собраны (`npm run build`) и раздаются одновременно — A на `:8144`, B на `:8145`.
Один и тот же сценарий (`script-compare.mjs`: онбординг → армия → первый бой → правила → развивай →
карта → настройки) прогнан в настоящем Chromium 153 на 1440×900 и 390×844, плюс точечные пробы
(`script-probe-battle.mjs`) на бой в 390 и 360 px. Тесты: `npm test` и `npx tsc --noEmit` в обеих
версиях.

Обе версии прошли проверку без JS-ошибок (`pageerror` пусто, в консоли только шум мока
`ERR_CONNECTION_CLOSED`). Мобильный скролл у B в бою не ломает игру: карты листаются по-горизонтали,
стрелка вверх подтверждает, что обе версии играбельны.

## Решение

Выбран **вариант A**, из B перенесена группировка моделей по семействам брендов (развилка 10).
Нижняя навигация поверх боя и блок ополчения за экраном из B в выбранный вариант не попадают.

## Дефекты, найденные этим прогоном

- **B, 360×740:** «Конец хода» и правый край руки перекрыты нижней навигацией (та остаётся видимой
  поверх боя). На 390×844 перекрытие на грани (кнопка влезает, 4-я карта обрезана).
- **B, 390×844:** блок выбора ополчения находится ниже списка колоды — чтобы назначить бойцов, надо
  проскроллить «Армию» (снимок `branch/m390-03-army-picked.png`).
- **A:** набор проверок 360×740 был шире (последний прогон на 360 — из проб). Признанных дефектов нет:
  обе найденные по ходу проверки проблемы (оверфлоу «Армии» 474→390 px, наложение «ОПОЛЧ.» на имя
  карты) исправлены и повторно проверены.
