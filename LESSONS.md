# LESSONS — заметки для будущих сессий

## Сессия 1

- README содержит важное ограничение: сессии 1–2 не должны добавлять игровую
  логику. Даже если хочется быстрее прототипировать, сначала нужно закрепить
  дизайн и архитектуру.
- Так как жанр был пустым, стартовая сессия началась с вопросов человеку. Ответы
  нужно считать частью проектной памяти: roguelike-арена + лёгкий постапокалипсис.
- Для маленькой тактической игры выгодно держать правила отдельно от DOM. Это
  упростит unit-тесты и поможет будущим сессиям не ломать уже работающие правила.
- Не стоит добавлять React/Vue/Svelte без явной необходимости: на MLP хватит Vite,
  TypeScript и тонкого DOM-рендера.
- CI должен запускать не только тесты, но и production-сборку, потому что Vercel
  будет деплоить именно build-результат. Но workflow-файлы нельзя пушить через
  текущий GitHub App без permission `workflows`; пока это право не выдано, CI нужно
  держать в backlog и обязательно гонять `npm test` / `npm run build` локально.
