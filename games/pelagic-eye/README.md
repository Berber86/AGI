# Тишина рифа — Pelagic Eye

Подводная обсерватория на React, TypeScript и Three.js. Архивная версия была приложением Vite; здесь она сохранена как исходники и собрана в самостоятельную HTML-страницу для каталога.

## Запуск из каталога

Корневая `index.html` каталога ведёт на `play/index.html` — production-сборку игры. Вся игра, стили и шрифты вшиты в один HTML-файл: дополнительные запросы к CDN, сервер приложений и каталоги с ресурсами не нужны. Для WebGL и разрешения камеры лучше открывать страницу через HTTP(S), а доступ к камере браузеры дают только в защищённом контексте (HTTPS или `localhost`).

## Разработка и обновление сборки

Требуется Node.js 22 или новее. Команды выполняются из этого каталога:

```sh
npm ci
npm run dev -- --port 5173
npm run check
npm run export:static
```

`npm run export:static` собирает React/Vite-приложение в `dist/`, проверяет, что HTML не ссылается на отдельные скрипты, стили или внешние ресурсы, и обновляет `play/index.html`. `dist/` и `node_modules/` — временные каталоги, в Git остаются исходники и опубликованный HTML.

## Управление

- Начните погружение и спокойно наблюдайте за рифом; движение не требуется.
- Смотрите на обитателей, чтобы открывать записи в полевом журнале.
- Панель VR-драйвера включает режим линзовых очков, гироскоп и калибровку камеры по меткам.
- Настройки качества, звука и движения доступны из паузы; коллекция и настройки сохраняются в `localStorage`.

В VR-режиме камера-метки требуют разрешения на камеру. При недоступном WebGL браузер покажет объяснение вместо игрового мира.
