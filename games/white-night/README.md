# Белая ночь — Бюро находок

Небольшая самостоятельная 3D-игра на **Three.js + Vite**. Белая ночь, двор-колодец на Петроградской стороне, один бак и 18 находок. Предыдущая игра и исходники skill не изменены.

## Запуск из общего каталога

В корневом `index.html` есть карточка «Белая ночь» с обложкой и кнопкой **Играть**. Она открывает `games/white-night/play/index.html`: готовую локальную сборку, которая хранится в Git, чтобы обычный статический хостинг работал **без Node.js и Vite**.

Из корня репозитория: `python3 -m http.server 8000` — затем откройте общий каталог. На статическом хостинге достаточно файлов репозитория; никаких дополнительных настроек сборки не нужно. Для WebGL используйте браузер с аппаратным ускорением, а для service worker — HTTPS или localhost.

После изменения исходников обновляйте опубликованные файлы:

```sh
cd games/white-night
npm ci
npm run export:static
npm run test:catalog
```

`export:static` пересобирает `dist/`, затем полностью обновляет `play/`, удаляя устаревшие хешированные файлы. Коммитьте исходники и обновлённый `play/` вместе. Это намеренное небольшое исключение для каталога статических игр: `node_modules/` и промежуточный `dist/` по-прежнему не входят в Git.

## Играть

- Трижды нажмите на бак либо на «Порыться в баке».
- Поверните найденную вещь пальцем или перетаскиванием мышью.
- **✕** — выбросить; **✓** — забрать.
- В коллекции можно заново осмотреть сохранённые вещи. Повторы не увеличивают число уникальных находок.
- Соберите **12 вещей с историей + 6 видов хлама**. При 18/18 появится завершение; после него можно продолжать.
- В настройках — инструкция, облегчённая графика и сброс с подтверждением. Игра намеренно без звука и проигрыша.

## Запуск

Node.js 22.12+; команды из этого каталога:

```sh
npm ci
npm run dev -- --port 5173
```

Production preview:

```sh
npm run build
npm run preview -- --port 5173
```

Сервер слушает `0.0.0.0`, поддерживает проксированное Arena-превью. Нет runtime-зависимостей от CDN, аккаунтов, API или внешнего сервера. Файлы исходного `index.html` не предназначены для открытия через `file://` — используйте Vite либо production-сборку.

## Статическая публикация

Содержимое `dist/` можно раздать любым статическим сервером, в том числе из подкаталога на GitHub Pages. Vite использует относительный `base: './'`. Сборка генерирует service worker с хешем версии и списком локальных ресурсов; старые кэши этой игры удаляются после обновления. Для установки PWA и офлайна нужен HTTPS либо localhost. После первой успешной загрузки production-версии работает офлайн. `dist/` и `node_modules/` не входят в Git. Постоянная публикация в этой сессии не выполнялась.

Прогресс хранится в `localStorage`, ключ `white-night-finds-v1`. Очистка данных сайта удалит коллекцию. Если хранилище недоступно, игра продолжает работать и предупреждает, что прогресс временный.

## Проверки

```sh
npm run check       # syntax
npm test            # 7 deterministic reducer/storage tests
npm run build       # relative static bundle + generated offline cache
npm run test:e2e    # production subpath server + real Chromium touch checks
npm run gate        # all four above
npm run test:desktop # production preview must be running at port 5173
npm run test:catalog # переход из корневого каталога на обычном статическом сервере
npm audit
```

`test:e2e` запускает собственный временный HTTP-сервер и Chromium, доставляемый npm-пакетом `@sparticuz/chromium`. Linux-библиотеки распаковываются в `/tmp`; root-доступ и apt не нужны. Software WebGL здесь медленный: полный прогон занимает примерно 8 минут. Desktop-проверка занимает около 3 минут. Тестовый интерфейс включается **только** параметром `?test=1`; обычная игра не выставляет методы изменения состояния.

Результаты и скриншоты находятся в корневом `.studio/evidence/`:

- `reports/core.json`: 7 unit-проверок;
- `reports/e2e.json`: 16 групп проверок production-версии, два мобильных размера, все модели, офлайн, сохранение, сброс и отсутствие ошибок;
- `reports/desktop.json`: мышь, Escape, горизонтальный экран;
- `reports/release.json`: финальные размеры сборки и ограничения.

Полный mobile E2E был выполнен до двух точечных исправлений (Escape и высота горизонтального экрана); оба исправления затем проверены отдельным production desktop/landscape прогоном, а syntax, unit и build повторены.

## Устройство

- `src/state.js` — каталог, чистые переходы, сохранение и взвешенный выбор;
- `src/models.js` — 18 настоящих вращаемых 3D-моделей;
- `src/world.js` — двор, бак, материалы, камера, свет, рендер и кеш моделей;
- `src/materials.js` — локальные процедурные текстуры и материалы;
- `src/main.js` — интерфейс, pointer input, диалоги, lifecycle;
- `src/style.css` — вертикальный мобильный и широкий desktop интерфейс;
- `scripts/service-worker.mjs` — production offline cache.

## Художественные материалы и ограничения

Модели созданы программно. Карта штукатурки `public/assets/plaster.jpg` сгенерирована ИИ и сжата до 1024². Остальные фактуры и текстовые этикетки создаются локально через Canvas. Шрифты Manrope и Cormorant Garamond поставляются локально через Fontsource; лицензии сохранены в `licenses/`. Three.js использует MIT License.

Это компактная атмосферная браузерная игра, **не AAA-производство**: нет сканированных моделей, трассировки лучей, сложной физики или настоящего открытого города. Белая ночь и дата/время — художественная сцена, не live-погода. Веса редкостей постоянны, защита от невезения не включена (не была утверждена).

Цель — 30 FPS на поддерживаемых мобильных устройствах; **на физическом Android не проверено**. Программный SwiftShader не даёт валидного заключения о производительности телефона. DPR ограничен 1.5; облегчённый режим ограничивает DPR до 1 и выключает тени. Нет звука по утверждённому контракту. Проверка visibility в E2E синтетическая, не настоящая блокировка экрана телефона.
