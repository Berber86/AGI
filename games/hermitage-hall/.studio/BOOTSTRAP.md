# Эрмитаж · Парадный зал — bootstrap

Этот каталог — источник правды по проекту `games/hermitage-hall`. Корневой `.studio/`
принадлежит игре «Белая ночь», его трогать нельзя.

## Начало сессии

1. Прочитать `request.md`, `discovery.json`, `game.json`, `state.json`, `backlog.json`.
2. Прочитать последний файл в `handoffs/`.
3. Свериться с `acceptance.md`: что уже подтверждено, что нет.
4. Убедиться, что контракт `approved`; менять его можно только с записью в `decisions.md`.
5. Проверить, что живые проверки не устарели: `npm run gate` (юнит + сборка + e2e).

## Конец сессии

1. `npm run check && npm test` — обязательно; `npm run gate` — если менялась сцена.
2. Обновить `acceptance.md` и `state.json` (валидный JSON, атомарно).
3. Дописать `decisions.md` и `lessons.md`, не переписывая историю.
4. Положить отчёт e2e в `evidence/reports/`, кадры — в `../evidence/screenshots/`.
5. Написать датированный `handoffs/*.md` с точными командами, результатами и блокерами.

## Границы

- Один зал, девять точек, шесть картин, две скульптуры. Новые залы и ходьба — вне контракта.
- Никаких внешних CDN в рантайме и никаких новых 3D-ассетов без лицензии в `licenses/`.
- `.studio` в корне репозитория не изменять.
