# Уроки

## Смена мобильного вьюпорта в Puppeteer перезагружает страницу

**Симптом.** После `page.setViewport({ isMobile: true, hasTouch: true })` вызовы
`window.__HERMITAGE__` падают: API ещё не создан.
**Причина.** Puppeteer меняет `isMobile`/`hasTouch` только перезагрузкой страницы.
**Исправление.** После смены вьюпорта ждать `window.__READY__ === true` и заново вызывать
`enter()`. Кадры снимать на отдельной странице, а не после смены вьюпорта.
**Проверка.** `tests/e2e.mjs` 26/26 и `tests/shot.mjs` проходят целиком.

## Медальоны на высоте 0,62 м требовали наклона > 16°

**Симптом.** Двелль не срабатывал: угол до медальона превышал допуск 6°.
**Причина.** Медальон висел низко, а взгляд по умолчанию горизонтальный.
**Исправление.** Медальоны подняты на 1,45 м (уровень глаз), допуск 6°, а наведение идёт
на медальон (`markerPose`), а не на якорь экспоната.
**Проверка.** e2e: 9,98 с до прибытия.

## Толстая коробка стен перекрывала солнце

**Симптом.** В зале было темно, окна не давали света.
**Причина.** Стены были собраны сплошным боксом вокруг сцены.
**Исправление.** Тонкие «кожухи» по сегментам стены, свет проходит через проёмы.
**Проверка.** Кадры `evidence/screenshots/final/03-point-p1.jpg`.

## Service worker в dev-режиме отдавал index.html вместо sw.js

**Симптом.** `unsupported MIME type ('text/html')` в консоли и падение e2e.
**Причина.** В dev нет `sw.js`, dev-сервер отвечал HTML-фолбэком.
**Исправление.** Регистрация только при `import.meta.env.PROD`.
**Проверка.** e2e на dev и на production без ошибок.

## Смена ракурса взглядом на соседний медальон не сбрасывает двелль

**Симптом.** Тест «уход взгляда сбрасывает прогресс» иногда проходил неправильно.
**Причина.** `yaw + 0,5` всё ещё попадал в соседний медальон.
**Исправление.** В тесте уходить на `yaw + π`.
**Проверка.** `tests/logic.test.js`, стабильный прогон.
