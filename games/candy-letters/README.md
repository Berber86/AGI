# Сладкие буквы

Обучающая браузерная игра для ребёнка 4–7 лет, который учится читать и писать русские буквы.
Первый набор — пять букв **А О У М С**.

Игра без сборки: статическая страница, чистые ES-модули и canvas. Всё рисуется векторно,
внешних файлов и CDN нет, весь пакет — меньше 120 КБ.

## Что делает ребёнок

Круг на одну букву (2–3 минуты):

1. **Карточка буквы.** Большой леденец с буквой, вкус и слово-пример. Тап по леденцу — игра
   произносит звук буквы.
2. **Обводка глазурью.** Вафельная клетка, пунктир по порядку штрихов, номер первого штриха
   и бегунок-подсказка. Оценка честная: считается покрытие штриха и доля глазури, ушедшей в
   сторону. Три попытки, без наказания — «обведём ещё раз, медленно».
3. **«Услышь и найди».** Игра произносит звук, ребёнок выбирает нужный леденец из пяти.
   Три верных ответа — дальше. Ошибка забирает одну конфетку из трёх.
4. **Письмо по памяти.** Пустая вафельная клетка с бледной канавкой буквы. Две попытки; после
   второй наклейка выдаётся за старание, чтобы ребёнок не застревал.
5. **Наклейка.** Пять наклеек — «Коробка сладостей собрана!».

Поражения нет: когда конфетки кончились, показывается «Коробка опустела — но буквы остались»
и кнопка «Попробовать ещё». Прогресс сохраняется в localStorage и не сбрасывается.

## Родительский режим

Кнопка «Взрослым» в меню: сколько наклеек собрано, сколько было попыток обводки и ошибок на
слух, какой русский голос найден в системе, выбор любой буквы, переключатель звука и сброс
прогресса.

## Как запустить

```bash
cd games/candy-letters
python3 -m http.server 5173 --bind 0.0.0.0 --directory play
# открыть http://localhost:5173/
```

Или из корня репозитория: `python3 -m http.server 8899` и
`http://localhost:8899/games/candy-letters/play/`.

Страница работает и как PWA: манифест + service worker кэшируют весь пакет, установка на
планшет и офлайн после первой загрузки.

## Проверки

```bash
cd games/candy-letters
npm test          # 33 юнит-теста: данные букв, геометрия, оценка обводки, редьюсер состояний
```

Браузерная проверка (headless Chromium + статический сервер из корня репозитория):

```bash
GAME_URL=http://127.0.0.1:8899/games/candy-letters/play/ \
  node tests/browser.mjs
```

Она проходит полный круг настоящими движениями указателя по canvas, проверяет оба исхода,
перезагрузку, родительский сброс, два мобильных ландшафтных вьюпорта, отсутствие ошибок консоли
и внешних запросов, бюджет кадра и вес ассетов. Отчёт пишется в
`.studio/evidence/reports/candy-letters-round.json`, скриншоты — в
`.studio/evidence/screenshots/`.

## Устройство

| Файл | Назначение |
|---|---|
| `play/assets/letters.js` | данные пяти букв: штрихи в сетке 100×100, цвет, вкус, слово, озвучка |
| `play/assets/paths.js` | разворачивание кривых в ломаную, метки вдоль штриха, геометрия доски |
| `play/assets/tracing.js` | детерминированная оценка обводки (покрытие + «блуждающая» глазурь) |
| `play/assets/state.js` | чистый редьюсер: экраны, задания, конфетки, наклейки, победа |
| `play/assets/render.js` | кондитерская страна, леденцы, вафельная доска, конфетти |
| `play/assets/audio.js` | русская озвучка через Web Speech API + запасные WebAudio-эффекты |
| `play/assets/main.js` | связка состояния, касаний, отрисовки и озвучки, мост `window.__GAME_TEST__` |
| `scripts/build_icons.py` | генератор иконок и заглушки обложки без зависимостей |

Логика (`letters`, `paths`, `tracing`, `state`) не трогает DOM — поэтому её можно гонять
в node и она же работает в браузере.

### Голос

Озвучка использует русский голос системы (`ru-RU`). Если русского голоса нет, игра не молчит:
звучат мягкие мелодии, а причина видна в родительском режиме. Это проверено в headless-браузере,
где голосов нет вовсе.

### Тестовый мост

`window.__GAME_TEST__` умеет: `getState`, `getSummary`, `dispatch`, `reset(seed)`,
`idealStrokes(letterId)`, `submitIdealTrace`, `submitIdealWrite`, `benchFrame(count)`,
`clockProgress()`, `audio()`.

## Ограничения

- Пять букв (А О У М С), остальные 28 — вне текущего объёма.
- Горизонтальная ориентация; в портрете показывается подсказка повернуть устройство.
- Оценка обводки — геометрическая, а не распознавание рукописного текста: она прощает дрожание
  руки и требует попадания в коридор штриха.
- Голос зависит от системы: на Android обычно есть русский TTS, на десктопном Linux его может
  не быть — тогда звучат только эффекты.
