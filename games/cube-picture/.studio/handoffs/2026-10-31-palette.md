# Handoff 2026-10-31 — палитра по фото реальных кубиков (FIELD-001)

## Сделано
- `src/pictures.js`: палитра по фото пользователя — Y жёлтый, R красный, K розовый, P фиолетовый, G зелёный,
  B тёмно-синий (`rel` = цвет кубика / цвет серого листа); C голубой и L сиреневый — `decoy:true`
  (распознаются, чтобы не засчитывать их за B/P, в картинках не используются). `PLAY_COLORS`, `MAX_PER_COLOR = 2`.
  8 картинок перерисованы под 6 цветов, ≤2 кубика каждого цвета.
- `src/vision.js`: деление на фон → цветность; первый проход оценивает общий сдвиг log-светлоты сцены
  (медиана по уверенным пикселям), второй добавляет светлоту (lumScale 0.2); тёмные почти серые пиксели
  (y < darkY 0.55) — тоже кандидаты; связные области по каждому цвету отдельно.
- `src/anim.js`: огонь ракеты — нижний кубик; `src/app.js`: логотип из `PLAY_COLORS`.
- Тесты: `tests/png.mjs` (декодер PNG), `tests/fixtures-real-cubes.png` (80×80 вырезки Y,R,K,P,G,B,C,L,фон с фото);
  сцены с реальными текстурами, «ловушки» C/L, яркость ×1.4/×0.75. Деревянный стол убран (не поддерживается).
