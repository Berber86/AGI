# Кубик-картинка 📷

Детская игра (3–5 лет, без текста): **телефон показывает картинку из 3–10 цветных кубиков →
ребёнок выкладывает её на столе из настоящих кубиков → фотографирует → игра проверяет сборку
и, если всё верно, картинка оживает.**

Играть: `games/cube-picture/index.html` (нужен HTTPS или localhost — иначе браузер не даст камеру;
GitHub Pages подходит).

## Как играть

1. На карте выбрать картинку (следующая непройденная покачивается).
2. Образец + ряд «что понадобится» (столько маленьких кубиков каждого цвета, сколько нужно).
3. Кнопка 📷 → камера с рамкой. Выложить кубики на **светлом однотонном фоне** (лист бумаги)
   и снять **сверху**, чтобы все кубики были внутри рамки.
   Когда игра «видит» верную сборку, рамка и кнопка затвора становятся зелёными.
4. Проверка → **оживление** + звезда, или экран «почти»: неверные кубики обведены красным
   на фото (в углу — кубик нужного цвета или ✕ «здесь пусто») и на образце.

Повёрнутая на 90°/180°/270° сборка засчитывается. Проиграть нельзя.

Меню для взрослых — **удерживать шестерёнку 1 секунду**: советы по съёмке, звук, сброс звёзд.
Если камера недоступна (запрет, старый браузер), подсвечивается кнопка с картинкой —
можно снять системной камерой или выбрать фото из галереи.

## Палитра

Настроена по фото настоящих кубиков (`src/pictures.js` → `PALETTE`), экран калибровки не нужен:

| Буква | Цвет | Как видит камера (отн. серого листа) |
|---|---|---|
| `Y` | жёлтый | 1.15 · 0.88 · 0.39 |
| `R` | красный | 1.12 · 0.54 · 0.60 |
| `K` | розовый | 0.97 · 0.48 · 0.67 |
| `P` | фиолетовый | 0.61 · 0.46 · 0.65 |
| `G` | зелёный (тёмный) | 0.40 · 0.52 · 0.47 |
| `B` | тёмно-синий | 0.30 · 0.37 · 0.62 |
| `C`, `L` | голубой, сиреневый — **ловушки** | есть в наборе, но в картинках не используются |

`rel` — цвет кубика, делённый на цвет фона (R·G·B). Цвета-«ловушки» нужны, чтобы голубой не засчитывался
за синий, а сиреневый — за фиолетовый: такие пары почти совпадают по оттенку и различаются светлотой.
Чтобы перенастроить под другие кубики: сфотографировать их сверху на сером/белом листе, взять медиану
цвета каждого кубика, поделить на медиану листа и записать в `rel`.

## Как работает проверка (`src/vision.js`)

Без ML и без сети, ~10 мс на снимок:

1. Кадр «рамка + поле 14%» уменьшается до 160 px (усреднение = шумоподавление).
2. Фон = медиана цвета по краю кадра; каждый пиксель делится на фон (баланс белого и экспозиция).
3. Пиксель — кандидат в кубик, если заметно отличается от фона и либо окрашен, либо заметно темнее
   фона (тёмно-зелёный почти серый).
4. Цвет — ближайший эталон по цветности; затем по уверенным пикселям оценивается общая светлота
   сцены (белая бумага ярче серой ткани), и второй проход добавляет светлоту — так отличаются
   синий/голубой и фиолетовый/сиреневый.
5. Связные области **по каждому цвету отдельно**: выкидываются крошки и всё, что касается края
   кадра (рука, складка листа), — не утаскивая за собой кубики.
6. Наклон раскладки — по направлениям краёв кубиков (усреднение `cos 4θ, sin 4θ` градиента).
7. Рамка кубиков делится на сетку картинки в 4 поворотах; в центре каждой клетки голосование за цвет.
8. Выбирается поворот с наименьшим числом ошибок; засчитывается только полное совпадение.

## Проверки

```bash
node games/cube-picture/tests/vision.test.mjs   # 577 проверок: синтетика + текстуры реальных кубиков
python3 -m http.server 8899 &                   # из корня репозитория
node games/cube-picture/tests/e2e.mjs           # headless Chromium (см. references/headless-browser-setup.md)
```

`vision.test.mjs` для каждой картинки: верная сборка (прямо, повороты 90/180/270, наклон до 35°,
белая бумага, серый стол, кубики ярче/темнее, настоящие текстуры кубиков с фото (`tests/fixtures-real-cubes.png`)
прямо/с наклоном/с ярким и тёплым светом, тёплый/холодный свет, шум, мелкие кубики, неаккуратная раскладка
с зазорами, съёмка под углом, рука у края, крошка, «всё сразу»), каждый кубик по очереди другого
цвета (ошибка должна указываться ровно в этой клетке), убран, белый; голубой вместо синего
и сиреневый вместо фиолетового не засчитываются; лишний кубик; пустой стол;
ни одна картинка не засчитывается за другую.

`e2e.mjs` — фейковая камера Chromium показывает видео со сборкой: живой предпросмотр узнаёт её,
снимок засчитывается, звезда сохраняется; ошибка и пустой стол; все 8 анимаций (кадры меняются);
пауза камеры при сворачивании; запасной путь «фото из файла» при запрещённой камере; меню взрослых
по удержанию; отсутствие текста на детских экранах и ошибок в консоли; скриншоты 360×800 и 412×915
в `.studio/evidence/`.

## Ограничения

- Кубики должны лежать плоско одним слоем; башни/LEGO не поддерживаются.
- Нужен **светлый нейтральный** однотонный фон (белая бумага, серый лист). Деревянный/цветной стол
  сдвигает цвета (красный уходит в розовый) — не поддерживается; пёстрая скатерть мешает.
- Белые/чёрные/коричневые кубики не распознаются (не входят в палитру).
- Палитра проверена на текстурах с реального фото кубиков и синтетике; живой прогон на телефоне
  с камерой ещё не делался.
