# Саундтрек / Soundtrack

Положите сюда mp3-файл с именем **`soundtrack.mp3`**. Он станет музыкой игры.

```
games/candy-kingdom-coaster/assets/music/soundtrack.mp3
```

Как это работает (`src/music.js`):

- Песня играет по кругу в меню, в гонке и на финише.
  - В меню и на финишном экране громкость тише.
  - В гонке играет в полную громкость, на бусте чуть громче.
  - На «GO!» песня начинается сначала.
  - Пауза останавливает песню, продолжение запускает её с того же места.
  - Свёрнутая вкладка песню глушит.
- Кнопка звука выключает и песню.
- Если файла нет или он не читается, играет прежняя встроенная чиптюн-мелодия. Пока mp3 загружается, тоже звучит чиптюн, а затем он плавно переходит в песню.
- Service worker кеширует файл после первой загрузки, поэтому песня играет и офлайн. Замена файла подхватывается при следующем запуске с сетью.
- Громкость песни задаётся в `TRACK_LEVEL` в `src/music.js` (по умолчанию: меню 0.3, гонка 0.42, буст 0.5). Её подбирали так, чтобы громко сведённый трек не заглушал звуковые эффекты.

Рекомендации: 128–192 кбит/с, 44.1 кГц, до ~5 МБ. Лучше всего подходят треки, которые бесшовно зацикливаются.

---

Drop an mp3 named `soundtrack.mp3` here and it replaces the procedural chiptune. Without the file the game falls back to the built-in loop.
