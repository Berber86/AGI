🎮 Стенд задержки «телефон-джойстик»

Прототип к режиму «экран + джойстик» для Candy Kingdom Coaster. Замерить задержку нажатие → экран на ваших двух телефонах с VPN и решить по цифрам: хватит Firebase или нужен WebRTC. В игру стенд не встроен. Инструкция по бесплатному Firebase — в файле README рядом.
