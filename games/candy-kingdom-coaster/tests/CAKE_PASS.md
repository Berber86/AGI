# Два торта-серпантина

Изменение от 2026-10-14: клубнично-сливочный подъём → вафельный мост → шоколадно-вишнёвый спуск. Участок встроен после второго трамплина, перед финальным замком.

## Устройство

- `src/cake-course.js` — единая геометрия маршрута и координаты ориентиров. Каждый серпантин делает 1,25 оборота; набор/сброс высоты — 34 м, верхний мост — 92 м.
- Длина маршрута теперь ≈2310 м (вставлено ≈837,5 м). Въезд начинается на 1344,6 м, подъём — на 1408,6 м, мост — на 1709,6 м, спуск — на 1801,6 м, возврат на обычную трассу — на 2182,1 м.
- Движение машины, дорожное полотно, перила и декорации используют один сплайн. Стыки имеют непрерывные положение и касательную; таблица длины дуги достаточно плотная для равномерной скорости на витках.
- Старые декорации получают исходную шкалу расстояний через `track.scenery`. Река, тоннель, трамплины, последовательность зон и финальный замок не переезжают на витки. Обочины плавно исчезают перед высотной частью и возвращаются после неё.
- Пороги коллекционных медалей не изменены. Временная медаль масштабирована до 165 секунд под увеличенную трассу. Старые локальные рекорды не удаляются.
- Новые изображения и зависимости движка не нужны: используются процедурная геометрия, две небольшие canvas-текстуры коржей и существующие карты дороги/вафель/карамели. Декорации объединены в 28 мешей, 122048 треугольников (без самой дорожной ленты).
- Удалено пересечение фоновой горы с новой трассой. Арочные опоры моста вынесены из нижнего витка. PWA-кеш обновлён до `ckc-v15-cake-pass`; регистрация работает и после завершившегося события `load`.

Node-тест не требует npm-пакетов: Node ≥22.15 и локальная копия Three.js. Browser QA использует уже принятый в репозитории инструментальный стек; установка описана в `.agents/skills/arena-game-forge/references/headless-browser-setup.md`.

```bash
# Сервер из корня репозитория (в отдельном процессе):
python3 -m http.server 8899 --bind 0.0.0.0

# После установки puppeteer-core и @sparticuz/chromium в /home/user/tools:
node games/candy-kingdom-coaster/tests/tools/setup-runtime.mjs
cp games/candy-kingdom-coaster/tests/tools/*.mjs /home/user/tools/
node /home/user/tools/cakeqa.mjs
node /home/user/tools/acceptance.mjs
node /home/user/tools/gameqa.mjs
```

Для сервера, отдающего непосредственно каталог игры, передать `BASE=http://127.0.0.1:3000/index.html` в `cakeqa.mjs`; `acceptance.mjs` и `gameqa.mjs` принимают URL первым аргументом.

Браузерные отчёт и четыре кадра сохраняются в игнорируемой `.playwright/cakes/` (либо `CKC_EVIDENCE`). Тестовый API: `window.__TEST__.cakeInfo()`; геометрия/сцена — `window.__TEST__.internals()`. Бинарные evidence не добавлены в Git. Проверки выполнены в Chromium/SwiftShader, а не на физическом Android: реальная частота кадров на устройстве не измерялась.
