# Машина «Star Racer 7», версия 2 — свидетельства

Переработка героической машины: вместо стопки скруглённых коробок — «листовая»
модель (три лофта кузова с настоящими колёсными арками, единая поверхность палубы
с проёмом кокпита, револьверные шины, диск с текстурой и вентиляционными
отверстиями) плюс восемь сгенерированных текстур машины и процедурные карты
(шероховатость лака, clearcoat-искры, грани протектора, шкалы приборов).

| Файл | Что показывает |
|---|---|
| `before-hero-front.png`, `before-side-left.png` | исходная модель до переработки (85 мешей, 16.9 тыс. треугольников, «блочный» силуэт) |
| `fin-hero-front.png`, `fin-hero-low.png`, `fin-side-right.png` | новая модель: арки с хромированной окантовкой, фонари, решётка, бамперы с «клыками», пончиковый спойлер, спутнер-леденец |

| `contact-sheet.png` | все кадры студии одной картинкой |

## Как воспроизвести

```bash
# статический сервер из корня репозитория
python3 -m http.server 8899 --bind 127.0.0.1

# быстрая студия (рендерит только машину — секунды вместо минут)
cd games/candy-kingdom-coaster
node tests/tools/car-studio.mjs /tmp/shots --width 1600 --height 900 \
  --prefix fin hero-front hero-low side-right cockpit wheel-rear

# кадры внутри игры (полный мир, медленнее)
node tests/tools/shot.mjs /tmp/shots \
  "ingame-race:0.155:0:1" "ingame-intro:intro:0.55:0" "ingame-boost:boost:0.62:1.5:1" "ingame-close:close:0.155:0"
```

Ограничения: решётка радиатора — плоская «плита» с планками (не сквозная),
секции кузова сшиты внахлёст, а не единой оболочкой; «сквозные» отверстия в
диске — только пять вентиляционных, лепестки непрозрачны.
