# Первичный бульон: Микрогенез

Отдельная мобильная 3D-игра в репозитории Arena Game Forge. Для текущей approved-версии используются TypeScript, Babylon.js и Vite; игровые файлы и тесты находятся только в этом каталоге.

## Запуск

```bash
npm install
npm run dev
```

Откройте локальный адрес Vite в альбомной ориентации. Для публичного Arena preview сервер привязывается к `0.0.0.0`; разрешён домен `.e2b.app`.

## Управление и мутации (текущий срез)

- Виртуальный джойстик находится слева; справа — кнопки «Кусать» и «Рывок», сверху — ручная пауза. Если свернуть/скрыть игру, экспедиция автоматически ставится на паузу и продолжается при возвращении.
- Укус рядом с мелкой добычей даёт ДНК и биомассу. Пороги биомассы 36 и 72 автоматически открывают редактор и дают по 1 ДНК на одно изменение слота.
- В редакторе два активных слота; каждый ростовой этап позволяет изменить один. Слоты можно заполнить жгутиком, ресничками, шипами или хоботком.
- После второй мутации появляется светлый разлом, который охраняет ускорившийся хищник; доберись до разлома, чтобы завершить экспедицию.
- Жгутик ускоряет плавание на 35%; реснички увеличивают радиус сбора на 55%; шипы отбрасывают хищника; хоботок увеличивает дальность укуса и добычу на 50%.
- HUD показывает активную сборку, подсвечивает добычу в радиусе укуса и предупреждает о близком хищнике; в финале стрелка ведёт к светлому разлому.
- После трёх делений здоровья экспедиция завершается; после победы или поражения можно начать заново.
- Production build генерирует service worker с precache всего локального app shell и bundle; после первой успешной загрузки игру можно открыть офлайн.

## Проверки

```bash
npm test
npm run check
npm run build
LD_LIBRARY_PATH=/tmp/lib npm run test:e2e

# Проверка офлайн-старта production build:
npm run preview -- --port 4173
BASE_URL=http://127.0.0.1:4173/ LD_LIBRARY_PATH=/tmp/lib npm run test:pwa
```

Browser smoke запускается через Puppeteer + Chromium из npm-пакета `@sparticuz/chromium`. На чистой Linux-песочнице сначала распакуйте Chromium и его системные библиотеки из `node_modules/@sparticuz/chromium/bin` в `/tmp`, затем задайте `LD_LIBRARY_PATH=/tmp/lib`. Скрипт создаёт machine-readable отчёты и скриншоты под корневым `.studio/evidence/`. Размеры viewport можно задать через `VIEWPORT_WIDTH` и `VIEWPORT_HEIGHT`.
