# Первичный бульон: Микрогенез

Отдельная мобильная 3D-игра в репозитории Arena Game Forge. Для текущей approved-версии используются TypeScript, Babylon.js и Vite; игровые файлы и тесты находятся только в этом каталоге.

## Запуск

```bash
npm install
npm run dev
```

Откройте локальный адрес Vite в альбомной ориентации. Для публичного Arena preview сервер привязывается к `0.0.0.0`; разрешён домен `.e2b.app`.

## Управление и мутации (текущий срез)

- Виртуальный джойстик находится слева; справа — кнопки «Кусать» и «Рывок».
- Укус рядом с мелкой добычей даёт ДНК и биомассу. После первой ДНК появляется кнопка редактора.
- В редакторе два активных слота. Выбор нового органа стоит 1 ДНК на слот; слоты можно заполнить жгутиком, ресничками, шипами или хоботком.
- Жгутик ускоряет плавание на 35%; реснички увеличивают радиус сбора на 55%; шипы отбрасывают хищника; хоботок увеличивает дальность укуса и добычу на 50%.
- Ростовые пороги, которые будут ограничивать мутации в финальном цикле экспедиции, ещё не подключены.

## Проверки

```bash
npm test
npm run check
npm run build
LD_LIBRARY_PATH=/tmp/al2023/lib npm run test:e2e
```

Browser smoke запускается через Puppeteer + Chromium из npm-пакета `@sparticuz/chromium`. На чистой Linux-песочнице сначала распакуйте Chromium и его системные библиотеки из `node_modules/@sparticuz/chromium/bin` в `/tmp`, затем укажите `LD_LIBRARY_PATH=/tmp/al2023/lib`. Скрипт создаёт machine-readable отчёты и скриншоты под корневым `.studio/evidence/`.
