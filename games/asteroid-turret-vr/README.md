# Астероидный рубеж — VR-турель

Неоновый шутер обороны космического корабля. Взгляд вращает лазерную турель;
**1,5 с концентрации взгляда** на астероиде (неоновое кольцо зарядки, при срыве
взгляда прогресс тает, а не обнуляется) — и лазер стреляет сам. Астероиды одного
типа бесконечным, умеренным потоком приближаются только из сектора **90°×60°**
перед игроком; скорость и плотность плавно растут ~8 минут до предела. Пропущенный
астероид бьёт по корпусу (100 ед.), при нуле забег закончен, рекорд сохраняется.

## Режимы взгляда (экран подготовки, внутри очков — ноль интерфейса)

- **Плоский экран** — мышь/палец.
- **VR-гироскоп** — стереопара для линзовых очков, DeviceOrientation; выход:
  Esc / системный «назад» / невидимый long-press ~0,9 с.
- **VR-fusion** — гироскоп ведёт каждый кадр, пара цветных меток (розовая слева,
  оранжевая справа) через Worker/HSV медленно правит дрейф: сущность ≥0,15 с,
  только пара доказывает «прямо», потеря пары — удержание без возврата в центр,
  поправка ограничена по скорости и требует подтверждения.

Качество VR выбирается только вручную (высокое/лёгкое) и не меняется в сессии.
Звук минимальный синтезированный: выстрел и взрыв (WebAudio после жеста).

## Разработка

```bash
npm install
npm run check        # 14 unit-тестов: sim + look
npm run dev
npm run export:static  # -> play/
node qa/e2e.mjs        # нужен headless-Chromium стенд (см. qa/e2e.mjs, QA_BASE)
```

Тестовый мост: `window.__GAME_TEST__` (`start/reset/step/state/setLook/camFeed/
camCalibrate/info`). Состояние поля: синтетика зелёная (unit 14/14, E2E 9/9),
физический знак гироскопа и живая камера — **not device-tested**.
