## What changed
- `src/world.js` (new): все процедурные текстуры (камень+бамп с кратерами,
  газовый гигант с пятном шторма, туманность 1024px, палуба), окружение
  (небо-сфера, 2 слоя звёзд, планета с кольцами и атмосферой, луна, маяки,
  240 пылинок мимо корабля), корабль (клин-нос, панельная палуба, вращающийся
  воротник турели, спаренные стволы, боковые пушки, ходовые огни, свечение
  двигателя), астероиды detail-2 с хэш-шумом (3 визуальных варианта одного
  механического типа).
- `src/fx.js` (new): FxSystem — луч (ядро+оболочка), вспышка выстрела, пул
  частиц 520, осколки, ударные волны-кольца, пуловый свет взрыва.
- `src/main.js`: ACES/сRGB/AA, hemisphere+rim свет, двойная дуга dwell +
  скобки на цели, тряска камеры при ударе ТОЛЬКО на плоском экране.
- Экран подготовки: баннер из игрового кадра; обложка каталога обновлена.

## Visual review loop (screenshots actually inspected)
1. Тёмный клин слева = плоскость колец планеты при взгляде вверх-влево ->
   планета унесена вниз-влево, кольца уменьшены.
2. Квадратные точки звёзд/пыли -> glow-текстуры на Points.
3. «Зеркальный монитор» головы турели -> голова ниже/темнее/меньше.
4. Насыщенность туманности снижена (color tint + alpha облаков).
