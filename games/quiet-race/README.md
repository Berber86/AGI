# Тихая гонка 🏁

Неспешная гоночная игра для маленькой гонщицы (5 лет). Здесь нельзя проиграть: заезд всегда
заканчивается финишем-праздником, кубок и медаль получают все — и героиня, и друзья-соперники.

Сделано по контракту из `.studio/game.json` (проект ведётся по воркфлоу `arena-game-forge`).

## Что происходит в игре

1. **Гараж** — выбор цвета машинки, флажка и наклейки. Никакого текста: только картинки.
2. **Светофор** — голос говорит «Три… два… один… Едем!», лампочки загораются по очереди.
3. **Дорога** — машинка едет сама, ребёнок только рулит. По пути шарики (радость и счёт),
   плюс кочки и лужи с брызгами.
4. **Обгоны** — три друга едут по трассе; обгон отмечается звёздочкой и приветствием.
5. **Финиш** — клетчатый флаг, ленточка, конфетти, кубок и медаль всем; большая кнопка «Ещё раз».
   Следующий заезд — в новом месте: лес → река → город → снова лес.

## Управление

- **Горизонтально** (телефон на бок). В вертикальном положении появляется добрая подсказка
  «Поверни телефон», а не сломанная игра.
- Две большие кнопки в нижних углах: **держи левую — поворот налево, держи правую — направо**.
- Скорость автоматическая, разгон и торможение ребёнку не нужны.
- Для родителя: кнопка **тихо** (динамик) в гараже, в заезде и на финише; игра сама встаёт
  на паузу, если свернуть браузер или переключиться на другое приложение.

## Как запустить на телефоне

1. Открыть адрес игры в Chrome на Android.
2. Меню Chrome → **«Добавить на главный экран»** — появится иконка, игра откроется на весь экран.
3. После первой загрузки игра работает без интернета (сервис-воркер кэширует сборку).

## Команды разработки

```bash
npm install        # зависимости (Phaser, Vite, TypeScript, Vitest)
npm run dev        # локальный сервер разработки, слушает 0.0.0.0
npm test           # 11 детерминированных тестов симуляции заезда
npm run build      # статическая сборка в dist/ (относительные пути, ~1.5 МБ)
npm run preview    # предпросмотр production-сборки
```

Проверки-доказательства:

```bash
npx vite build --config vite.headless.config.ts   # сборка для безголового прогона
node scripts/headless-run.mjs                     # настоящие касания → заезд → финиш + скриншоты
python3 scripts/make_icons.py                     # перегенерировать иконки PWA (только stdlib)
```

Результаты безголового прогона: `.studio/evidence/reports/headless-run.json`
и скриншоты `.studio/evidence/screenshots/headless-*.png`.

## Как это устроено

```text
src/sim/          детерминированная симуляция заезда (без Phaser, тестируется в Vitest)
  config.ts       все числа: скорости, трава, отсчёт, длина трассы
  rng.ts          seeded PRNG (mulberry32)
  race.ts         createRace / stepRace / события (светофор, обгон, шарик, брызги, финиш)
src/game/         слой отображения
  textures.ts     вся графика рисуется кодом на canvas-текстурах (ассетов нет)
  audio.ts        WebAudio-музыка, звуки и русский голос (Web Speech API)
  layout.ts       геометрия экрана 1600×800 и дороги
  ui.ts           крупные круглые кнопки, конфетти, звёздочки
  bridge.ts       window.__GAME_TEST__ для автотестов и прогонов
  scenes/         GarageScene, RaceScene, FinishScene, OverlayScene
tests/race.spec.ts  инварианты: отсчёт, финиш 40–60 с, трава, шарики, кочки, заморозка финиша
```

Отдельных файлов-ассетов нет вообще: изображения создаются процедурно, звук синтезируется,
речь идёт через системный голос. Поэтому сборка весит 1.5 МБ и мгновенно работает офлайн.

## Что проверено, а что нет

**Проверено:** 11 автотестов симуляции; безголовый прогон игры (jsdom + Skia-канвас) с настоящими
касаниями от гаража до финиша, включая замедление на траве, возвращение на дорогу, «Ещё раз»;
production-сборка; относительные пути и файлы PWA.

**Не проверено:** живой запуск на Android-телефоне (в песочнице нет устройства и не запускается
Chromium), реальный офлайн-режим после установки, звучание русского голоса на конкретном телефоне.
