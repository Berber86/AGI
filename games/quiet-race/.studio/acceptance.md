# Критерии приёмки «Тихая гонка»

Авторитетный контракт — `.studio/game.json`. Здесь только проверяемые пункты и их фактический статус.

## Ворота discovery

- [x] Запланировано 2–4 этапа брейншторма (3 этапа: творческое направление, игровой опыт, фиксация контракта).
- [x] Использованы структурированные вопросы с вариантами ответа (по 4 вопроса на этап).
- [x] Контракт показан пользователю текстом до начала работы.
- [x] Контракт явно утверждён: вариант «Утвердить MVP», название «Тихая гонка».

## Ворота играбельности (вертикальный срез)

- [x] Один полный заезд проходится: гараж → светофор → дорога → финиш → «В гараж»/«Едем!».
- [x] Касания меняют состояние: руление меняет `lateral`, трава включает замедление (`speed` 84 → 60), возвращение на дорогу снова ускоряет (60 → 76 и выше).
- [x] Путь финиша, возвращение в гараж и повторный заезд продемонстрированы прогоном `npm run qa`.
- [x] Проигрыш отсутствует по замыслу: нет таймера, жизней и Game Over; трава только замедляет.
- [x] 11 детерминированных автотестов симуляции проходят (`npm test`).
- [x] Чистый проезд укладывается в 40–60 секунд: `drivingMs 43517` + отсчёт 4.2 с = 47.7 с (seed 4321).
- [x] Все три обгона случаются в чистом заезде (`overtakes: 3`).

## Мобильные ворота

- [x] Управление только касаниями: две большие кнопки-полукруга, без клавиатуры и наведения.
- [x] Заезд отыгран в размере мобильного ландшафта 915×412 через настоящие touch-события.
- [~] Вертикальный размер 360×800 проверен частично: подтверждено, что включается подсказка «Поверни телефон» и игра не ломается; полноценная проверка на устройстве — нет.
- [x] Пауза при сворачивании реализована (visibilitychange/blur → пауза с кнопкой продолжения).
- [x] Звук разблокируется после первого касания (`audio.unlock()` на pointerdown).
- [x] Игра не ломается без русского голоса и без доступа к хранилищу (проверено запуском со `file://`, где `localStorage` недоступен).

- [x] Пути относительные (`base: './'`), сервис-воркер регистрируется по `./sw.js` со scope каталога сборки.

- [x] Автономный файл проверен запуском: `npm run qa:offline` (загрузка, заезд, финиш, без ошибок).

- [x] Лёгкие доказательства и известные ограничения записаны в handoff.

## Что осталось доказать (честно)

- Заезд на живом Android-телефоне: **не проверено**. В песочнице нет устройства, а Chromium не запускается
  (недоступны системные библиотеки, репозитории Debian закрыты). Вместо этого игра прогоняется в jsdom
  со Skia-канвасом — это подтверждает логику, отрисовку и реакцию на касания, но не заменяет телефон.
- Установка PWA и реальный офлайн после первой загрузки на телефоне: проверены только файлы и пути.
- Голос: зависит от установленного русского голоса в системе; без него остаются музыкальные сигналы.
