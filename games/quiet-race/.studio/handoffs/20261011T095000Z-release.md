## Что сделано

- Полная игра «Тихая гонка»: гараж (цвет/флажок/наклейка картинками) → светофор «Три, два, один — едем!» →
  дорога (автоматическая скорость, две большие кнопки руления, шарики, кочки, лужи, три друга-соперника) →
  клетчатый флаг, ленточка, конфетти, кубок и медаль всем → «Ещё раз» / «В гараж».
- Три темы заезда по кругу: лес → река → город. Сложность не растёт; проигрыша нет по замыслу.
- Вся графика рисуется кодом, весь звук синтезируется, речь идёт через Web Speech API: отдельных файлов-ассетов нет.
- Приложение PWA: манифест, иконки 192/512, сервис-воркер с кэшем оболочки.
- Дополнительно: автономный однофайловый вариант сборки для игры без сервера и интернета.
- 11 автотестов симуляции, безголовые прогоны (ландшафт + портрет) и прогон автономного файла.

## Решения

- Игра живёт вне репозитория `Berber86/AGI`: его `AGENTS.md` прямо запрещает добавлять сгенерированные игры.
- Phaser в режиме Canvas, вся графика — процедурные текстуры; это выполняет бюджет 8 МБ и требование работы без сети.
- Размер интерактивной зоны контейнера считается от `displayOrigin` (см. `lessons.md`).
- Фактор скорости друзей 0.84 — чтобы все три обгона случались в заезде из ~45 секунд.

## Блокеры и риски

- **Не проверено на живом Android-телефоне.** В песочнице нет устройства, а Chromium не запускается
  (нет системных библиотек, репозитории Debian недоступны). Прогон в jsdom + Skia-канвасе — замена, но не телефон.
- Установка PWA и офлайн после первой загрузки на телефоне проверены только по файлам и путям.
- Русский голос зависит от системного голоса; без него игра остаётся на музыкальных сигналах.
