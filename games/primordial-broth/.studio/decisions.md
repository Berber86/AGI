## 2026-10-14T00:26:31Z — Процесс: циклы улучшения и пуш каждую 4-ю итерацию

- **Решение:** после вертикального среза работаем циклами «скриншот → сравнение с эталоном Spore → правка → контрольный кадр». Каждая 4-я итерация завершается `git push` и паузой для комментариев пользователя.
- **Альтернативы:** непрерывные улучшения без пушей (отвергнуто пользователем — теряется контроль), пуш после каждой итерации (слишком часто).
- **Причина:** пользователь хочет участвовать в отборе правок и видеть стабильные вехи.
- **Затронуто:** процесс сессий, `state.json`, этого навыка acceptance не меняет.

## 2026-10-14T08:05:40Z — Технический профиль: vanilla ES-модули + Canvas 2D вместо Phaser/TS

- **Решение:** игра написана на нативных ES-модулях и Canvas 2D, без сборщика.
- **Альтернативы:** Phaser + TypeScript + Vite (профиль по умолчанию скилла), Babylon.js.
- **Причина:** «живая вода» — это сотни полупрозрачных слоёв, боке, лучей и каустик, которые надо
  рисовать напрямую; Canvas 2D даёт полный контроль и нулевой вес движка. Плюс игра запускается
  как статика из подкаталога GitHub Pages без сборки, как и предыдущая игра репозитория.
- **Цена:** нет типов и готовых систем ввода/сцен — компенсировано собственным тест-мостом
  `window.__GAME_TEST__` и приёмочным набором из 13 проверок.
- **Затронуто:** game.json → technical.profile, структура src/, tests/tools/.

## 2026-10-14T08:05:40Z — Мягкое поражение реализовано как «отдышался», без экрана проигрыша

- **Решение:** при нуле здоровья клетка теряет ~28% несобранной биомассы, получает 2.4 с неуязвимости,
