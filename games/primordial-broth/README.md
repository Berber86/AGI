# Первичный бульон 🌊

Мобильная браузерная игра про стадию «первичного бульона»: ты — только что вылупившаяся клетка,
которая ест планктон, растёт, приращивает себе части тела и прорывается к отмели.

Сделана по skill `arena-game-forge` (см. `.studio/` — контракт, бэклог, решения, handoff).

## Как играть

- **Палец в любом месте экрана** — тяга в сторону пальца (инерция и разворот, как мышью в Spore).
- **КНОПКА «РЫВОК»** справа внизу — ускорение (тратит запас сил, потом восстанавливается).
- Кнопки сверху справа — звук, пауза, полный экран.
- Телефон держите **горизонтально**.

Три поколения: на каждом «росте» (3/8, 6/8, 8/8) открывается выбор одной из трёх ДНК-частей —
жгутик, реснички, шипы, жало, яд, электричество, челюсть. Части остаются навсегда, даже если вас чуть не съели.
Победа — дорасти до 8/8 и доплыть до отмели на востоке.

## Запуск

Игра — статическая, сборка не нужна:

```bash
python3 -m http.server 8080     # из корня репозитория
# открыть http://localhost:8080/games/primordial-broth/index.html
```

Параметры в URL (для отладки и тестов): `?seed=7` (детерминированный старт), `?nohud=1`, `?q=low`.

## Проверки

```bash
# headless-тулчейн (chromium + puppeteer + статический сервер на 8899)
bash games/primordial-broth/tests/tools/bootstrap.sh

cd /home/user/tools          # скрипты копируются туда bootstrap'ом
node acceptance.mjs          # 13 приёмочных проверок -> /home/user/shots/acceptance.json
PORTRAIT=1 node acceptance.mjs   # то же на 412×915
node shot.mjs /tmp/out ev-play:play ev-shore:shore   # контрольные кадры
node cellqa.mjs /tmp/out     # крупные планы существ
```

Приёмочный набор проверяет: загрузку, управление пальцем (реальный drag через Pointer Events),
рост биомассы, смену размера, экран мутации и применение части, мягкое поражение с сохранением
прогресса, укус хищника, победу, рестарт, паузу, полноту HUD, живучесть пищевой цепочки и чистую консоль.

## Архитектура

```
index.html            разметка HUD и экранов
styles.css            оформление HUD (композиция как в референсе Spore)
src/config.js         весь тюнинг: размеры, скорости, части, палитры
src/main.js           игровой цикл, экосистема, бой, рост, победа + тест-мост window.__GAME_TEST__
src/water.js          «живая вода»: параллакс-боке, лучи, каустики, колонии, пузыри
src/cell.js           процедурный рендер существ: тело по следу движения, части, глаза
src/fauna.js          виды существ и их поведение (планктон, крошки, стайки, пасущиеся, хищники, споры)
src/fx.js             частицы, всплывающие числа, кольца
src/audio.js          процедурный WebAudio (без ассетов)
src/hud.js            DOM-HUD, миникарта, экран мутации, итоги
src/mutations.js      части тела и их влияние на физику/бой
tests/tools/*.mjs     приёмка, скриншоты, крупные планы, bootstrap окружения
tests/reference/      эталонные кадры Spore для сравнения
tests/evidence/       контрольные кадры, сохранённые как доказательства
```

Ассетов-файлов нет: вся графика рисуется кодом (Canvas 2D + процедурные спрайты), звук — WebAudio.
Поэтому вес игры — это только код (десятки килобайт), а бюджет ассетов из контракта не расходуется.

## Честные ограничения

- Проверка шла в headless-Chromium со SwiftShader (программный растеризатор): на нём 35–50 FPS.
  На реальном Android-устройстве ожидается 60 FPS, но **живого телефона в песочнице нет** — замер на устройстве не проводился.
- Сравнение с эталонным кадром Spore — визуальное, по контрольным кадрам `tests/evidence/`.
- Офлайн-режим включается только на https-хостинге (service worker не регистрируется на localhost).
