# ⚙ По силам — конвейер нового типа

ИИ-помощник, переработанный вокруг **двух реально работающих механизмов**
(вместо классического «конвейера списков», который для большинства не работает).

**v0.3.0 «скелет быта»** — возврат из старой конвейерной концепции необходимого
жизненного скелета: **сроки** (`due`), **рутины-повторы** (`repeat`) и горизонты
склада. Обязательства сами всплывают на экране «Сегодня» (секции «⏱ По сроку» и
«↻ Рутины») **вне бюджета и квоты**; просроченное обходится прощающими кнопками
«→ завтра» / «снять срок» — система по-прежнему не создаёт стыда.

## Два механизма — и вся система

### 1. Аффект-фильтр + протокол избегания
Прокрастинация — не лень и не дыра в плане, а **избегание неприятной эмоции**
(Pychyl, Sirois; behavioral activation). Поэтому:

- каждое дело на складе несёт **ожидаемую эмоцию** (скука / тревога / тяжесть /
  «непонятно как» / стыд) и уровень **сопротивления** 0–3;
- дела с сопротивлением ≥2 попадают в **зону избегания** — там работает протокол, а не воля;
- **протокол избегания** (4 шага):
  1. назвать страх/эмоцию (аффект-лейблинг снижает её силу) + оценка «насколько будет тяжело»;
  2. письменное разрешение: «имею право сделать ПЛОХО, только 2 минуты» + микро-шаг;
  3. таймер 2 минуты — старт впереди мотивации;
  4. сверка «что было на самом деле» → пара «предсказание / факт».
- экран «Данные» показывает главную метрику: **насколько часто страх преувеличивает**.

ИИ здесь ровно один раз и по делу: подсказать варианты страха и микро-шаг в протоколе.

### 2. Планирование «по силам» + квота-шторка
Система обслуживает оператора, а не список:

- утренний **чекин сил** (1–5) — единственный вход для планирования;
- **бюджет дня** = уровень сил (единицы стоимости дел: лёгкое 1 / среднее 2 / тяжёлое 3);
- **квота** = мин(силы, максимум); слот **«на радость»** — один в день и бесплатный
  (анти-инструментализация: радость не тратит бюджет);
- набрали план или квоту — **шторка**: «день закрыт», остальное спит до завтра.
  В системе нет просроченных и нет бэклога-виновника: пропуск — данные о ресурсе;
- вечерний микро-разбор «как прошёл день» — одним тапом.

## Экраны

- **Сегодня**: чекин сил → бюджет/квота → план (с запуском протокола) → шторка → вечерний тап;
- **Склад**: быстрый захват, аффект-фильтр, зона избегания, история протоколов по делу;
- **Данные**: «страх преувеличил в N% случаев», силы по дням, сверки протокола, закрытые квоты;
- **Настройки**: правила квоты, ИИ-ключ (OpenAI-совместимый API), Firebase, экспорт/импорт.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173 (слушает 0.0.0.0)
npm test        # 14 тестов ядра: бюджет, квота, шторка, протокол, миграция
npm run check   # типы
npm run build   # прод-сборка
```

Данные — в localStorage; ключи вводятся в «Настройках» и хранятся только в браузере.
Firebase Firestore — опциональная синхронизация (`selfConveyor/state`).
Данные старого формата (v1) автоматически переносятся на склад при первом запуске.

## Что намеренно убрано (старая концепция)

Списки «желания → фильтр → ТОП-5 → цели → проекты», колесо баланса, SMART,
помодоро, метрики, дневники, метапроекты, ретро/HADI — всё, что лечит
**планирование** вместо **эмоций и ресурса**. Два механизма — минимум, который
реально двигает поведение; остальное — накладные расходы, убивающие систему.

## Принципиальные решения

- система платит из своего же топлива: максимум действий пользователя — 2–3 тапа;
- избегание — данные, а не провал; страх почти всегда преувеличивает (и система это доказывает цифрами);
- квота и шторка защищают от «жизни-бэклога»; у системы есть слово «хватит»;
- перенос в отдельный репозиторий: папка `games/self-conveyor/` самодостаточна.
