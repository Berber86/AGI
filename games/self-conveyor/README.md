# ⚙ Конвейер управления собой (Self Conveyor)

ИИ-помощник персональной системы продуктивности «Конвейер управления собой»
(методика: потоковая система списков от желаний до результата).

MVP строится **в три итерации**, чтобы не распылять внимание и хорошо сделать базу:

| Итерация | Статус | Содержание |
|---|---|---|
| **Этап 1 · База** | ✅ сделан основательно | ядро конвейера, «Сегодня», Помодоро, хранение, UX-фундамент |
| Этап 2 · Практики | 📝 сырой черновик | колесо баланса, «предсмертные» техники, фильтр+прокурор, метрики, дневники |
| Этап 3 · Автоматизация | 📝 сырой черновик | ИИ-триаж, метапроекты, ретро PDCA, HADI, шаблоны |

Разделы черновиков в интерфейсе помечены оранжевым баннером «Черновик этапа N»
и в текущей итерации не дорабатываются.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (слушает 0.0.0.0 — доступен и через превью)
npm test           # тесты ядра (17 шт.)
npm run check      # проверка типов TypeScript
npm run build      # прод-сборка в dist/
```

Данные по умолчанию хранятся в **localStorage браузера** — приложение работает сразу,
без каких-либо ключей. Ключи ИИ и Firebase вводятся в разделе «Настройки» и хранятся
только в браузере (в код репозитория не попадают).

## Этап 1 — База (что сделано основательно)

### Механика конвейера
- **Доска списков**: `Желания → Отфильтрованные → Приоритетные (ТОП-5) → Цели → Проекты → Сделано`
  плюс служебные `Срочные / Несрочные / Рутины / Шаблоны` (мелочь и повторы не прогоняются
  через весь конвейер — падают прямо в план дня).
- Перемещение: drag-and-drop между колонками **или** кнопка «→». Лимит **ровно 5 фокусов**
  блокирует шестой приоритет (правило «кувшина на 20 стаканов»).
- **Закрытие проекта всегда через проверку цели**: модалка показывает критерий достижения
  и прогресс шагов; если шаги не все — прямое предупреждение «шаги расписаны неверно,
  добавьте недостающие» (как в методике: вечерняя сверка «цель правда достигнута?»).
- Карточка-редактор (Escape — закрыть): измеримый **критерий достижения**, **осязаемый
  результат** (анти-ложная продуктивность), атомарные шаги с чекбоксом «сегодня», теги,
  дата, повтор для рутин, заметки.
- **Поиск** по карточкам (название, заметки, критерий, теги).
- **Быстрый захват** — поле вверху каждого экрана: мысль → Enter → сразу в «Желания».

### Сегодня и Помодоро
- План дня собирается из: шагов проектов (кнопка «☑ в сегодня» — все незакрытые разом),
  просроченных, рутин с наступившей датой и взятых дел; секция «Сделано сегодня»
  с возможностью вернуть в работу.
- **Помодоро** 25/5 с нормой 3–5 «помидорок» в день; счётчик за день сохраняется.
- Онбординг «5 шагов базы» для первого запуска (скрывается навсегда по кнопке).

### Хранение и надёжность
- localStorage с дебаунс-автосохранением и **индикатором времени сохранения**;
- опциональная синхронизация с **Firebase Firestore** (`selfConveyor/state`), автосейв +
  принудительные «сохранить/загрузить», миграция состояния при обновлении схемы;
- экспорт/импорт JSON (бэкап), полный сброс;
- **17 юнит-тестов ядра**: цепочка списков, лимит ТОП-5, сборка плана дня, атомарные шаги,
  рутины с датами, миграция состояния (`npm test`).

### ИИ на этапе 1 (только точечный, по делу)
- ✨ SMART-формулировка желания → цель («что сделать» / критерий / осязаемый результат);
- ✨ декомпозиция цели на атомарные шаги (вручную или через ИИ — «думать» отделено от «делать»).

## Черновик этапа 2 (сырой, не дорабатывается)

- Колесо баланса: сферы X/10, шаг X→X+1, радар, ИИ-штурм действий.
- «Предсмертные» техники: смертное ложе / диагноз 6 месяцев / бессмертие + ИИ-подсказки.
- Фильтрация желаний: 4 вопроса + «⚖ Прокурор (ИИ)».
- Метрики: замеры, спарклайны, рутины замеров.
- Дневники успеха и ложных опасений.

## Черновик этапа 3 (сырой, не дорабатывается)

- Входящее: ИИ-триаж потока мыслей → желания / проекты / мусор.
- Метапроекты-эпики (теги над проектами и рутинами).
- Ретро PDCA с авто-статистикой и ИИ-разбором; цикл HADI с предложением экспериментов.
- Шаблоны проектов с клонированием.

## Настройка ИИ

Любой провайдер с API в формате OpenAI `POST {baseUrl}/chat/completions`:

| Провайдер | Base URL | Пример модели |
|---|---|---|
| OpenRouter (один ключ = платные + бесплатные) | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini`, `meta-llama/llama-3.3-70b-instruct:free` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Локальный Ollama | `http://localhost:11434/v1` | `llama3.1` |

Кнопка «проверить подключение» в Настройках.

## Настройка Firebase (опционально)

Конфиг проекта (apiKey / authDomain / projectId / appId) — в «Настройки → Firebase».
Документ: коллекция `selfConveyor`, документ `state`. Правила Firestore настройте под себя.

## Принципиальные решения

- **Ключи и данные — в браузере**: запросы к LLM идут из браузера напрямую к провайдеру.
  Это персональный инструмент; не публикуйте сборку с чужими ключами.
- **ИИ — инструмент, а не хозяин**: ИИ-действия кнопочные, решения принимает человек.
- **Сначала база**: этапы 2–3 намеренно оставлены сырыми черновиками, чтобы не распылять
  внимание — они будут доводиться в своих итерациях.
- Перенос в отдельный репозиторий: папка `games/self-conveyor/` самодостаточна
  (`npm install && npm run dev`).
