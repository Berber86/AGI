# Установка, ключи, хранение

## Локальный запуск

```bash
cd games/self-conveyor
npm install
npm run dev        # http://localhost:5173 (слушает 0.0.0.0)
```

Прочие команды: `npm test` (тесты ядра), `npm run check` (типы),
`npm run build` (прод-сборка в `dist/`), `npm run preview` (превью сборки).

## Данные

- **Основное хранилище** — localStorage браузера, ключ `self-conveyor-state-v2`.
- При первом запуске автоматически мигрируются данные старого формата
  (ключ `self-conveyor-state-v1`): названия дел попадают на склад.
- **Бэкап**: «Настройки → Данные → экспорт JSON» (и импорт обратно).
- «Сбросить всё» — полная очистка (необратимо).

## ИИ-ключ (опционально, но рекомендуется)

ИИ используется в одном месте — подсказка страха и микро-шага в протоколе
избегания. Нужен любой провайдер с API в формате OpenAI
(`POST {baseUrl}/chat/completions`):

| Провайдер | Base URL | Пример модели |
|---|---|---|
| OpenRouter (один ключ = платные + бесплатные модели) | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini`, `meta-llama/llama-3.3-70b-instruct:free` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Локальный Ollama | `http://localhost:11434/v1` | `llama3.1` |

Ввод: «Настройки → ИИ». Кнопка «проверить подключение».
Модели с суффиксом `:free` у OpenRouter бесплатны (список моделей меняется —
смотрите актуальный каталог провайдера).

**Без ключа продукт полностью работает** — просто без ИИ-подсказок.

## Firebase Firestore (опционально)

Синхронизация состояния `selfConveyor/state` между устройствами.

1. В консоли Firebase создайте проект, включите **Firestore**.
2. Скопируйте web-конфиг (apiKey / authDomain / projectId / appId) в
   «Настройки → Firebase».
3. Настройте правила доступа под себя. Минимальный пример (доступ запрещён —
   подставьте своё условие, например, после Firebase Auth):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /selfConveyor/{doc} {
      allow read, write: if false;
    }
  }
}
```

Автосохранение — с дебаунсом после каждого изменения; плюс кнопки
«сохранить/загрузить вручную».

## Безопасность — читать обязательно

- Это **персональный инструмент**: API-ключ ИИ и конфиг Firebase хранятся
  в localStorage браузера в открытом виде и уходят напрямую к провайдерам.
- **Не публикуйте** свою сборку с введёнными ключами и не давайте её чужим.
- Не используйте ключи с крупными лимитами; для OpenRouter создайте отдельный
  ключ с бюджетным лимитом.
- Правила Firestore — ваша зона ответственности: «тестовый режим» даёт запись
  всем, у кого есть конфиг.

## Деплой

Сборка статическая (`play/`), подойдёт любой хостинг: GitHub Pages,
Netlify, Cloudflare Pages, обычный nginx. Ключи при деплое **не** зашиваются —
пользователь вводит их сам в «Настройках».

## Перенос в отдельный репозиторий

Папка `games/self-conveyor/` самодостаточна: копируйте её целиком
(без `node_modules/`), внутри — `npm install && npm run dev`.
