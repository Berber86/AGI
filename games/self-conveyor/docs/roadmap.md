# Дорожная карта

Итерации MVP. Правило отбора прежнее: **только механизмы с сильной базой и
минимальными накладными расходами**. Каждая итерация — работающий продукт.

## Итерация 1 — «База» (✅ текущая, v0.2.0)
Два механизма целиком:
- аффект-фильтр + протокол избегания + статистика «страх против факта»;
- чекин сил → бюджет → квота → шторка → вечерний тап;
- склад с захватом и зоной избегания; хранилище, миграция v1, экспорт/импорт,
  14 тестов ядра.

**Критерий успеха итерации (проверяем через 3–4 недели использования):**
система не заброшена после первой тяжёлой недели; статистика показывает
преувеличение страха; шторка реально опускается без чувства вины.

## Итерация 2 — «Среда и подкрепление» (следующая)

Кандидаты (отобраны по доказательной базе, см. science.md §5):

1. **Средовые шаги.** У каждого дела — не только «что сделать», но и «какую
   преграду убрать / какой сигнал сделать видимым» до начала (Wood, Fogg).
   Первый шаг проекта по умолчанию — средовой.
2. **If-then правила** (Gollwitzer): «если 9:00 и я за столом — 2 минуты на X»;
   хранение в делах, напоминание в плане дня.
3. **Temptation bundling** (Milkman): слот «на радость» привязывается к делу
   («только во время этого дела — этот подкаст»).
4. **Ритм вместо расписания**: система учит, в какие окна дела реально
   закрываются, и подсказывает их (без жёстких напоминаний).

**Не войдёт:** геймификация, стрики, штрафы (см. science.md §6).

## Итерация 3 — «Суд над системой» (финальная)

1. **Kill-criteria**: скрытые метрики жизни (энергия, сон, радость, близость —
   по дневным тапам и редким чекинам). Раз в месяц система выносит **себе**
   вердикт: «жизнь не улучшается → система виновата → упрощаем/выключаем».
2. **Список сознательных отказов** (антисписок) — равноправный документ
   «чего я НЕ делаю» (защита от тотальности).
3. **Provenance-фильтр** («чей это голос?»): при захвате — опциональная отметка
   источника желания; фильтр «тест не-заинтересованности» для крупных целей.
4. **Режимы профиля**: «выживание» / «обычный» / «ADHD» (новизна, body double,
   короткие циклы) — смена поведения системы, а не настроек вида.

## Принципы, по которым фичи отклоняются

- Требует от пользователя регулярного обслуживания > 2 минут в день → отклоняется.
- Добавляет чувство вины → отклоняется.
- Измеряет «продуктивность» вместо жизни → отклоняется.
- Дублирует два механизма иначе → отклоняется.

## Бэклог-кандидат (без обещаний)

- Виджет «одно дело на сейчас» для носилок (watch/lock screen).
- Импорт из существующих таск-трекеров (разовый) с авто-расстановкой
  стоимости/аффекта через ИИ.
- Совместный слот «на радость» (пара/друг) как социальное подкрепление.
