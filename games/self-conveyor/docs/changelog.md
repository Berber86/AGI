# История версий

Формат следует духу Keep a Changelog; версии — SemVer для приложения.

## [0.2.0] — «По силам» (текущая)
Полная переработка концепции вокруг двух механизмов.

### Добавлено
- **Аффект-фильтр**: у дела — ожидаемая эмоция и сопротивление 0–3;
  «Зона избегания» на складе.
- **Протокол избегания** (4 шага): назвать страх → разрешение «сделать плохо,
  на 2 минуты» → таймер-старт → сверка «что было на самом деле».
- **Метрика «страх преувеличил в N% случаев»** и экран «Данные».
- **Чекин сил 1–5 → бюджет дня → квота** (мин(силы, лимит)).
- **Шторка**: закрытый день не принимает дела; просроченных не существует.
- Слот **«на радость»** — бесплатный, один в день.
- Вечерний разбор одним тапом.
- Миграция данных v1 → v2.

### Удалено (по концепции, см. docs/concept.md)
Конвейер списков (желания → ТОП-5 → цели → проекты), SMART, колесо баланса,
«предсмертные» техники, помодоро 25/5, метрики-замеры, дневники,
метапроекты, ретро PDCA, HADI, ИИ-триаж входящего, шаблоны проектов.

## [0.1.x] — «Конвейер управления собой» (архив)
Классическая методика со списками, в три «этапа» итераций:
- **0.1.2** — итерация «База»: доска списков, drag-and-drop, ТОП-5, проверка
  цели при закрытии проекта, «Сегодня» + помодоро, онбординг, 17 тестов.
- **0.1.0** — первая сборка: конвейер списков + служебные списки, черновики
  этапов 2–3 (техники, метрики, дневники, триаж, метапроекты, ретро/HADI),
  Firebase, ИИ-инструменты.

Код v0.1.x доступен в истории git (коммиты `6f58689`, `1ebb5c3`, `e6138b1`).
