# История версий

Формат следует духу Keep a Changelog; версии — SemVer для приложения.

## [0.3.0] — скелет быта: сроки и рутины (текущая, итерация 2 MVP)
Возврат из конвейерной концепции (статья 1095804) необходимого жизненного
скелета — при строгом сохранении обоих механизмов «По силам».

### Добавлено
- **Сроки (обязательства)**: у дела появилось поле `due` (YYYY-MM-DD).
  Просроченные и сегодняшние обязательства сами всплывают на «Сегодня» в
  секциях «⏱ По сроку» и «↻ Рутины». Они **не тратят бюджет и квоту**:
  квота — про добровольную работу со склада, обязательства — про слово.
- **Прощающие действия для просроченного**: «→ завтра» и «снять срок»
  (дело возвращается на склад без даты) — без стыда и напоминаний.
- **Рутины (повторы)**: `repeat` — ежедневно / еженедельно / ежемесячно /
  ежеквартально / ежегодно. Отметка рутины двигает срок вперёд
  (`lastDoneAt` фиксируется), а не выбрасывает дело из склада.
- **Горизонты склада**: фильтры «все / просрочено / сегодня / до недели /
  без срока / рутины»; в редакторе — поле срока, быстрые чипы
  «сегодня / завтра / + неделя / без срока», выбор повтора и напоминание
  про честный тест «что будет, если просрочу?».
- Миграция: легаси `nextDue` (таймстамп v1 или строка) → `due`, `repeat`
  поднимается как есть.

### Изменено
- Зоны склада и избегания больше не дублируют друг друга: «Склад» —
  только сопротивление < 2, «🫁 Зона избегания» — только ≥ 2.
- Кнопка «☺ на радость» в кандидатах доступна всегда, а не только
  помеченным делам.
- Появились просроченные дела как корзина («просто есть»), но система
  по-прежнему не ругает.
- Тесты: 21 юнит-тест vitest (было 14).

### План (итерация 3+)
Триггеры/уведомления (система по-прежнему молчит сама — главный следующий
шаг), платформа дофамина (мост «сделал → награда»), версионирование
синхронизации вместо last-write-wins.

## [0.2.0] — «По силам»
Полная переработка концепции вокруг двух механизмов.

### Добавлено
- **Аффект-фильтр**: у дела — ожидаемая эмоция и сопротивление 0–3;
  «Зона избегания» на складе.
- **Протокол избегания** (4 шага): назвать страх → разрешение «сделать плохо,
  на 2 минуты» → таймер-старт → сверка «что было на самом деле».
- **Метрика «страх преувеличил в N% случаев»** и экран «Данные».
- **Чекин сил 1–5 → бюджет дня → квота** (мин(силы, лимит)).
- **Шторка**: закрытый день не принимает дела; просроченных не существует.
- Слот **«на радость»** — бесплатный, один в день.
- Вечерний разбор одним тапом.
- Миграция данных v1 → v2.

### Удалено (по концепции, см. docs/concept.md)
Конвейер списков (желания → ТОП-5 → цели → проекты), SMART, колесо баланса,
«предсмертные» техники, помодоро 25/5, метрики-замеры, дневники,
метапроекты, ретро PDCA, HADI, ИИ-триаж входящего, шаблоны проектов.

## [0.1.x] — «Конвейер управления собой» (архив)
Классическая методика со списками, в три «этапа» итераций:
- **0.1.2** — итерация «База»: доска списков, drag-and-drop, ТОП-5, проверка
  цели при закрытии проекта, «Сегодня» + помодоро, онбординг, 17 тестов.
- **0.1.0** — первая сборка: конвейер списков + служебные списки, черновики
  этапов 2–3 (техники, метрики, дневники, триаж, метапроекты, ретро/HADI),
  Firebase, ИИ-инструменты.

Код v0.1.x доступен в истории git (коммиты `6f58689`, `1ebb5c3`, `e6138b1`).
