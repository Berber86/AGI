# Шарик-непоседа 🌀

Детская игра для детей, которые **ещё не умеют читать**:
**перекатывай шарик по лабиринту, наклоняя телефон**.
На экране нет ни одного слова — только картинки, эмодзи и цифры.
Никаких кнопок управления шариком — только настоящие датчики телефона.

## Чистый экран

**Во время игры на экране нет ничего, кроме самого поля, шарика и звёздочек.**
Ни счётчиков, ни кнопок, ни индикаторов, ни всплывающих подсказок.
Поле занимает весь экран телефона.

Всё взрослое спрятано и появляется только между играми:

- стартовый экран — большая кнопка **📱 ▶️** (взрослый включает датчики);
- **удержание поля двумя пальцами (≈1 секунда)** — пауза для взрослых (ребёнок случайно не откроет):
  ▶ продолжить, 🎯 калибровка «это ровно», ↺ заново, 🗺️ уровни, 🔊 звук, ⛶ весь экран;
- после уровня — праздник 🎉 и ряд собранных звёздочек, кнопки ▶ ↺ 🗺️.

## Уровни: от простого к сложному

10 уровней по нарастающей. На уровне **N** нужно собрать ровно **N звёздочек**:

| Уровень | Звёзд | Что нового |
|---|---|---|
| 1 | ⭐ | Только периметр поля, внутри пусто |
| 2 | ⭐⭐ | Первые стенки-островки |
| 3 | ⭐⭐⭐ | Стены-коридоры и первая ямка |
| 4–5 | ⭐⭐⭐⭐(⭐) | Длинные коридоры, тупики, ямки |
| 6–7 | … | Лабиринт плотнее, проходы уже |
| 8–9 | … | Почти настоящий лабиринт |
| 10 | 🔟 | Самый сложный лабиринт и 10 звёздочек |

Каждый сбор звёздочки считается **вслух голосом** («один, два, три…»)
и ноткой всё выше — так к десятому уровню ребёнок проходит весь счёт до 10.
На экране при этом ни цифр, ни счётчиков нет — только игра.

Ямка не наказывает: шарик просто мягко возвращается на старт. Проиграть нельзя.

## Управление — целиком на датчиках

| Датчик | Событие браузера | Что даёт игре |
|---|---|---|
| Гироскоп | `DeviceOrientationEvent` (`beta`, `gamma`) | Углы наклона вперёд-назад и влево-вправо |
| Акселерометр | `DeviceMotionEvent` (`accelerationIncludingGravity`) | Куда «вниз» прямо сейчас |

Оба сигнала сливаются в один вектор наклона (55% + 45%), сглаживаются,
проходят мёртвую зону и поворачиваются под ориентацию экрана.
Ускорение шарика берётся **только** из этого вектора.

### На компьютере

Датчиков нет, поэтому наклон задают **стрелки клавиатуры** ←↑↓→ —
тот же вектор наклона, никаких экранных панелей и джойстиков на поле.

## Проверка

```bash
node games/tilt-ball-maze/tests/smoke.mjs
python3 -m http.server 8080   # из корня: /games/tilt-ball-maze/ (?emu=1 — сразу игра)
```

Проверки: файлы, оба датчика, калибровка, чистота экрана во время игры
(в разметке нет HUD), 10 уровней, у уровня N ровно N звёздочек,
первый уровень — только периметр, проходимость всех уровней (BFS),
ни одной буквы в видимом интерфейсе.

> ⚠️ Датчики движения браузеры отдают только по HTTPS или с localhost.
