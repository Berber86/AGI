# Мой пульт (`games/remote-hub`)

Единая точка входа для второго телефона (контроллера) при игре в VR на двух смартфонах по локальной точке доступа Wi-Fi — **без ручного ввода `firebaseConfig` и API-ключей**.

## Возможности
- **Общая пара один раз (`localStorage['agi_pair_v1']`)**: сканирование QR с экрана любой из игр сохраняет общую пару двух телефонов сразу для **«Сладкой Гонки»** (`joystick/`) и **«Белой ночи»** (`wrist/`).
- **Автоопределение активной игры (`whois` → `here`)**: при открытии «Мой пульт» автоматически опрашивает привязанный телефон-экран и мгновенно открывает нужный контроллер (руль + наклоны или 3D-рука + двухцветный маяк).
- **100% офлайн-маршрутизация (`AG1.<base64url>`)**: распознаёт компактные бинарные офлайн-приглашения WebRTC и переводит игрока прямо на экран ответного QR нужной игры даже без интернета на точке доступа.
- **PWA-кэш (`sw.js`)**: открывается мгновенно при подключении к локальной точке доступа без мобильных данных.
