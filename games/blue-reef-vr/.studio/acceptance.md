# Acceptance criteria

Авторитетные измеримые критерии зафиксированы в `game.json` после утверждения
контракта. Здесь — отметки о проверке.

## Discovery gate

- [x] Запланировано 3 этапа брейншторма.
- [x] Вопросы с вариантами ответов (2–4 на вопрос) и свободным ответом.
- [x] Контракт показан пользователю целиком.
- [x] Контракт явно утверждён (`approve`).

## Experience gate (вместо «round/win/lose»: у игры нет счёта и проигрыша)

- [x] Игра запускается и показывает мир без единого управления.
- [x] Обзор головой меняет кадр (параллакс и смена базиса подтверждены численно).
- [x] Кит появляется вдали и подходит ближе по расписанию (минимум 24.5 м).
- [x] Рыбы девяти видов двигаются (9 из 9 сдвинулись за 6 с).
- [x] Сеанс бесконечный: выход — снять очки или закрыть страницу.

## VR и метки

- [x] Стереопара включается только по явному действию.
- [x] Два квадрата по центру, одинакового размера (проверено по layout).
- [x] Базис 10–150 см, 64 см = 0.64 м в мировых единицах.
- [x] Режимы взгляда раздельны; гироскоп не используется никогда.
- [x] Пределы ±70° / ±45° соблюдаются даже при «безумных» углах.
- [x] Потеря метки удерживает угол: дрейф 0.00°, возврата к центру нет.
- [x] Калибровка пары требует обе метки; переставленные метки парой не признаны.
- [x] Метка подтверждается только после 0.15 с; круглое пятно отсекается.

## Mobile / release gate

- [x] Работает без клавиатуры и без hover (управления нет вообще).
- [x] Проверены «мобильные» вьюпорты 900×420, 640×320 при dpr 3 и 960×440.
- [x] Пауза при `visibilitychange`; время стоит и продолжается после возврата.
- [x] PWA: манифест, маскируемая иконка, офлайн-запуск без сети.
- [x] Относительные пути: игра работает из подпапки `/games/blue-reef-vr/`.
- [x] Нет ошибок страницы и консоли во всех прогонах.
- [ ] Живая проверка на Android в очках (устройства в песочнице нет).
- [ ] Замер FPS и нагрева на реальном телефоне.
