# Брейншторм «Голубого рифа VR»

> Статус: **утверждён пользователем (2026-10-17)**, реализовано в этот же день.

## Исходный запрос (дословно)

«Беря за образец игру про сладкие гонки сделай новую игру для vr очков с
метками(в той игре это все имеется). Про подводное плаванье где ребенок сможет
наблюдать проплывающих мимо руб, кораллы и даже кита. Уровень AAA графики. Пока
без управления. Лишь обзор головой по сторонам и вверх вниз»

## Этап 1 — Замысел

| Вопрос | Ответ | ID |
|---|---|---|
| Как ребёнок «плавает» | **Стоим на месте на поляне**: пловец парит над одной поляной рифа, мир живёт вокруг | `static_clearing` |
| Длительность сеанса | **Бесконечный маршрут**: выход — снять очки | `endless` |
| Кит | **Кит почти всё время вдалеке**, подплывает ближе | `distant_then_near` |
| Настроение | **Солнечный мелкий риф**: бирюза, столбы света, яркие рыбы | `sunny_shallow` |

## Этап 2 — Поведение и обзор

| Вопрос | Ответ | ID |
|---|---|---|
| Источник взгляда | **Только метки**: гироскоп не подключается вообще | `markers_only` |
| Пределы обзора | **±70° в стороны, ±45° вверх/вниз** | `middle` |
| Потеря метки | **Только удержание**: взгляд замирает, автопана нет | `hold_only` |
| Расстановка меток | **Две коробки шире**: спереди-слева и спереди-справа, 60–80° | `two_boxes_wide` |

## Этап 3 — Подача и контракт

| Вопрос | Ответ | ID |
|---|---|---|
| Качество vs плавность | **Три пресета вручную**: Красиво / Сбалансированно / Плавно | `manual_presets` |
| Бюджет «AAA» | **Жизнь**: косяки рыб, детальные кораллы, водоросли | `life` |
| Звук | **Без звука** | `silent` |
| Контракт | **Утверждаю этот MVP** | `approve` |

## Что следует из сочетания ответов

1. `static_clearing` + `endless` — сцена не должна «плыть» сама: вся жизнь
   вокруг (рыбы, кит, каустика, взвесь), камера стоит. Это же снимает главный
   риск укачивания.
2. `markers_only` — `deviceorientation` не слушаем нигде; в UI нет режима
   гироскопа, чтобы нельзя было случайно смешать источники.
3. `hold_only` — из образца не перенесены ни автопан, ни «выбег по вектору
   головы»: без данных угол не меняется вообще.
4. `two_boxes_wide` — коробки разнесены шире, чем в образце, поэтому рабочий
   диапазон поворота больше; плата — метки чаще уходят за оправу очков, это
   лечится удержанием из п. 3.
5. `manual_presets` — игра сама не снижает качество. Для VR честно рекомендуем
   «Плавно» текстом на экране подготовки.
