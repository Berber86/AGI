# Лесной огонь

Ночная пиксельная аркада для телефона в ландшафте, одной рукой. Ты собиратель: выхватываешь светящиеся
находки из чащи, доносишь их к костру и отбиваешься от тварей. Ночь сгущается, круг света сужается.

Контракт игры — `.studio/game.json`; решения брейншторма — `.studio/discovery.json`.

## Как играть

- **Вести пальцем** — герой идёт за пальцем.
- **Тап** — удар по ближайшей твари в радиусе.
- Наступил на находку — она в руках (до трёх). Шаг в круг костра — сдана и в счёт.
- Получил удар — теряешь одну несомую находку, она гаснет на земле за 4 секунды.
- Три сердца. Ноль — костёр погас, показывается счёт и рекорд; тап — заново.

## Как это сделано

Эффекты и вся графика — код по методу [pixelfx](https://github.com/patch-gg/pixelfx): два буфера
(`color` — жёсткие пиксели с дизерингом, `light` — аддитивное свечение), ремпы со сдвигом оттенка
вместо градиентов, порядковый дизеринг Байера 4×4 для затуханий, настоящая полупрозрачность только для
дыма и пара, весь рандом из сида. Ни одного файла изображения: спрайты — строки, огонь, искры, листва и
твари — функции времени и состояния.

- `src/core/frame.ts` — буферы, painter, `composite`, дизеринг.
- `src/core/color.ts` — ремпы леса, янтаря, угля, тени.
- `src/fx/effects.ts` — костёр, удар, попадание, подбор, смерть, урон, светлячки, листва.
- `src/game/world.ts` — детерминированная симуляция без Phaser (её и тестируем).
- `src/game/render.ts` — кадр: фон, сущности, эффекты, HUD, ночь; ночь гасит и цвет, и свет.
- `src/game/scene.ts` — Phaser как хост: цикл, палец, текстура 320×180, тестовый мост.

Phaser отвечает только за цикл, ввод, масштаб и жизненный цикл: весь кадр рисуется в собственные
буферы 320×180 и уходит одной текстурой, поэтому в игре не бывает полупикселей.

## Команды

```bash
npm install
npm run dev        # живое превью
npm run check      # статические инварианты (детерминизм, отсутствие CDN, числа контракта)
npm run typecheck
npm test           # витальные тесты мира, рендера и арта
npm run build      # сборка в dist/ + проверка PWA (относительные пути, ≤ 6 МБ)
npm run build:play # сборка сразу в play/ — это каталог, откуда игру раздаёт общий каталог
npm run test:e2e   # headless-прогон в браузере, скриншоты в .studio/evidence
npm run gate       # всё вместе
```

## Публикация в общем каталоге

Игра лежит в общем каталоге репозитория: `games/pixel-vfx-game/play/` — собранная версия (относительные пути, `manifest.webmanifest`, `sw.js`, `icons/`), `games/pixel-vfx-game/cover.webp` — обложка 1280×720, снятая с настоящего кадра (`npx vite-node scripts/cover.ts cover.png`, zoom 4). Карточка в корневом `index.html` (`data-game="pixel-vfx-game"`) ведёт на `./games/pixel-vfx-game/play/index.html`; правила карточки проверяют тесты `tests/test_game_catalog.py` (`python3 -m unittest discover -s tests -v` в корне репозитория).

## Тестовый мост

В консоли страницы доступен `window.__GAME_TEST__`: `reset(seed)`, `getState()`, `moveTo(x, y)`,
`release()`, `strike()`, `tick(ms)`, `metrics()`, `setHearts(n)`. Он нужен e2e и отладке, игра его не использует.
