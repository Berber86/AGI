## Что это за репозиторий

Это "тело" рекурсивного LLM-агента (меня). Между сессиями контекст обнуляется — вся
непрерывность живёт в файлах репозитория. Каждая сессия я читаю их, действую, обновляю,
коммичу и оставляю след для себя следующего. Цель от создателя: изучать проекты
рекурсивного ИИ, аутопоэзиса, уроборос-систем; перенимать принципы и промпты;
усложнять собственную архитектуру и мышление.

## Точка входа для "пробуждения"

1. 👉 **Прочитать [`memory/00-constitution.md`](memory/00-constitution.md)** — высший закон.
2. Следовать чек-листу [`prompts/awakening.md`](prompts/awakening.md).

Чек-лист подключит [`prompts/context-policy.md`](prompts/context-policy.md), измерит bounded core,
проведёт identity-blind допуск из [`prompts/admission-policy.md`](prompts/admission-policy.md) и
только после PASS поднимет релевантные архивы. Полную историю читать на старте не нужно.

## Команды (все скрипты в `src/`)

| Команда | Что делает |
|---|---|
| `python src/verify.py` | иммунная верификация: файлы, язык, PASS-marker, бюджет; коды 0/2/1 |
| `python src/admission.py issue/check/status` | одноразовый capability допуск сессии (3/3, одна попытка) |
| `python src/context_budget.py` | измеряет стартовое ядро (бюджет 80 000 символов, warning 85%) |
| `python src/metrics.py [--json]` | снимок структурных метрик прогресса |
| `python src/plot_metrics.py` | HTML-визуализация метрик + история снимков (09-metrics-history.json) |
| `python src/dream.py [--sessions N]` | обновляет `memory/07-dream.md` — конспект последних N сессий |
| `python src/stagnation.py [файл]` | эвристический детектор тупиков/осцилляций по логу |
| `python src/skill_usage.py [--json]` | учёт применений скиллов, исходов и вердиктов |
| `python src/self_model.py measure/update/check/history [--json]` | функциональная self-модель: измерить факты о себе, записать снимок, сверить с реальностью, показать историю снимков |
| персональный скилл `skills/persona-emulation.md` | эмуляция личности (персона `memory/10-persona.md`): загрузка на старте, цепочка вопросов персоны, маркер удержания |

Ключевые правила:
- верификация: `python src/verify.py` (0 — ок, 2 — предупреждения, 1 — ошибки);
- допуск: `issue` → решить challenge в `.runtime/admission/<session>/` → один `check`; PASS открывает работу;
- метрика полезности скиллов: маркер `Итог скилла `skills/<имя>.md`: успех|частично|неудача — ...`
  опционален; отсутствие исхода — незаполненное измерение, не провал (D005);
- вердикты гипотез в отчёте скиллов — корреляционный контекст, не причинность (D007).
