# ⚙️ Механизм Цивилизации (Cog Empires)

Стратегия, где вы развиваете упрощённую цивилизацию через дерево технологий с **синергиями иконок**, добываете редкие **шестерёнки** — модульные компоненты экипировки — и собираете из них **три отряда** для пошаговых автотактических боёв.

> 🎮 **Играть:** [GitHub Pages](https://berber86.github.io/AGI/) — после каждого коммита живая сборка обновляется автоматически.

## Жанровые референсы

- **Innovation (Carl Chudyk)** — технологии дают иконки, наборы иконок активируют «догмы»
- **Diablo / Path of Exile** — рандомный лут с редкостями, слияние предметов 3 → 1
- **Old Berserk CCG** — карты-персонажи с текстом способностей, риск-менеджмент боя
- **Slay the Spire** — узловая карта кампании: бой / элита / сокровище / привал / босс
- **Civilization** (упрощённо) — постройки, ресурсы, дерево технологий

## Как играть (5 минут)

1. **Армия** → наймите бойцов в 1–3 отряда, наденьте стартовые шестерёнки
2. **Кампания** → двигайтесь по узлам карты (бой → привал → элита → … → Босс)
3. **Победа в бою** = шестерёнки + день дохода; проигрыш = просто попробуйте иначе
4. **Технологии** → тратьте науку; иконки технологий активируют догмы-пассивки
5. **Мастерская** → сливайте 3 предмета одной редкости в 1 предмет выше (сет из 2+ входов наследуется)
6. Побеждайте **Босса** → новый **Цикл** (NG+): враги сильнее, добыча щедрее

## Управление боем

Бой — автотактика: вы влияете построением (5 линий × 10 колонок), экипировкой и таргетингом (зависит от рекрута и оружия). Внутри боя: скорость 1× / 2× / мгновенный итог. Ключевые механики: фаза внезапной атаки, криты/промахи/уклонение, яд, щиты, контратаки, мораль и **бегство**.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 49+ тестов движка (бой, экономика, лут)
npm run build      # прод-сборка в dist/
```

Весь геймплейный код — **чистые функции** (`src/engine/*`): никаких `Math.random`, DOM или localStorage внутри. Вся случайность входит через детерминированный RNG (`seed`). Это тестируется и готово к будущему серверу для PvP.

```
src/
├── data/       # контент: шестерёнки, техи, догмы, сеты, рекруты, здания, карта
├── engine/     # ЧИСТАЯ логика: unit/computeUnit, combat/simulateFight, economy, loot, campaign
├── store/      # Zustand-стор + localStorage-персистентность
├── components/ # React UI (только рендер)
└── utils/      # rng (mulberry32), форматирование
tests/          # Vitest: детерминизм боя, экономика, лут, сеты
docs/           # DESIGN.md (GDD), DATA_SCHEMA.md, DECISIONS.md, OPEN_QUESTIONS.md
```
