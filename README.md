# PALIMPSEST

**«Некоторые миры ждут, чтобы их вспомнили».**

Атмосферный симулятор космического археолога на Three.js. Это законченный **браузерный вертикальный срез** одной экспедиции, а не заявление о готовности полноценной AAA-игры.

## Экспедиция

На плато Эребуса сохранился архив исчезнувшей цивилизации. Исследуйте процедурный ландшафт, локализуйте три спектральных сигнала, очистите реликвии и восстановите последовательности символов. Три записи складываются в финальную историю.

- Настоящая интерактивная Three.js-сцена: сегментированные руины, эродированные горные гряды, камни, кольцевая планета, звёзды, пыль и атмосферная перспектива.
- Спектральная волна по поверхности ландшафта и привязанные к миру отметки.
- Свободное перемещение, обзор мышью или касанием, автоматический переход к объекту.
- Очистка удержанием кнопки, клавиатурой или повторными нажатиями; расшифровка трёх разных последовательностей.
- Карта сектора, полевой журнал, обзор без HUD, справка и настройки.
- Локальное сохранение, восстановление после перезагрузки, подтверждение сброса.
- Синтезированная звуковая атмосфера Web Audio, выключенная до явного действия пользователя.
- Адаптивные портретный и альбомный интерфейсы; режим производительности и уменьшение движения.
- Все шрифты и ресурсы локальные. После установки приложение не обращается к сторонним сервисам.

## Запуск

Требуется Node.js 20.19+ или 22+ и современный браузер с WebGL 2.

```bash
npm ci
npm run dev
```

Vite слушает `0.0.0.0:5173`. Хосты Arena `*.e2b.app` разрешены. В браузерном коде нет привязки к `localhost`.

```bash
npm run build
npm run preview
```

Для статического хостинга публикуйте `dist/`. Vite сообщает о размере основного чанка Three.js немного больше стандартного порога 500 kB; это предупреждение, не ошибка сборки. Движок вынесен в отдельный кэшируемый чанк.

| Действие | Управление |

## Подсистемы

| Модуль | Ответственность |
|---|---|
| `src/world.js` | Рендер, процедурная геометрия, материалы, свет, атмосфера, камера, сканирование, проекция отметок |
| `src/navigation.js` | Ограничение сектора и скользящие столкновения с основными колоннами |
| `src/state.js` | Чистая модель прогресса, валидация сохранений, очистка, расшифровка, финал |
| `src/main.js` | Сценарий, HUD, карта, журнал, модальные окна, управление и доступность |
| `src/audio.js` | Ветер, низкочастотная атмосфера, звуковая обратная связь |
| `src/style.css` | Визуальная система и адаптивные раскладки |
| `tests/`, `scripts/` | Модульная, браузерная и визуальная проверки |

Статические меши объединяются по материалам, 1 700 камней используют instancing, карта теней пересчитывается только при необходимости. На стартовом высоком качестве измерено **27 draw calls, 318 864 треугольника, 25 геометрий и 4 текстуры**. Во время работы в модальных окнах статичный фон не перерисовывается без необходимости. Эти показатели не являются обещанием конкретного FPS на всех устройствах.

## Проверки

```bash
npm test                 # 8 тестов модели состояния и навигации
npm run format:check
npm run build
```

При запущенном `npm run dev`, в другом терминале:

```bash
npm run test:e2e          # полное прохождение, звук, обзор, сохранение, сброс
npm run test:interaction  # мобильная лаборатория, указатель, фокус, аварийные состояния
npm run test:visual       # 1440×900, 390×844, 390×667, 844×390; снимки и границы панелей
```

Браузерные проверки по умолчанию используют Chromium из npm-пакета `@sparticuz/chromium` и рассчитаны на Linux x64. Если установлен свой Chrome/Chromium, задайте `CHROMIUM_PATH=/path/to/chromium`. Для полного E2E адрес можно изменить через `TEST_URL`. Визуальная проверка читает диагностический экспорт исходного Vite-модуля, поэтому запускайте её против dev-сервера.

Снимки сохраняются в `.playwright/` и намеренно не попадают в Git. Автоматическая проверка границ не заменяет визуальную оценку; проведённые циклы и замечания описаны в [docs/QA.md](docs/QA.md).

## Границы среза

- Один сектор, три реликвии и одна законченная сюжетная линия.
- Стилизованная процедурная графика, без фотограмметрии, скелетной анимации и кинематографических роликов.
- Столкновения — приближения для основных колонн, не полноценный физический движок. Переход к реликвии — направляемое перемещение камеры, не navmesh-поиск пути.
- Кислород, погода и связь — художественная телеметрия, не симуляция выживания и не сетевое соединение. Карта схематична.
- Автосохранение действует в пределах текущего браузера и origin. Настройки графики и звука действуют до перезагрузки. Бэкенда нет.
- Реальные мобильные GPU, Safari/Firefox и субъективное качество звука требуют отдельного аппаратного/слухового тестирования. Здесь проверен Chromium со SwiftShader.

## Ресурсы

Manrope и Space Grotesk распространяются по SIL Open Font License; лицензии лежат рядом со шрифтами в `public/fonts/`. Иконки — Lucide (ISC). Ландшафт, геометрия, материалы, иллюстрации реликвий и звук созданы программно.

## Продолжение: трёхмерная полевая лаборатория

Реликвии в лаборатории теперь используют те же модели Three.js, что и находки
в мире: обсидиановый осколок с гравировкой, многокольцевой компас и узел архива.
Перетаскивайте объект для осмотра; колесо мыши или жест двумя пальцами меняет
масштаб. При фокусе на модели доступны стрелки, `+` / `−` и `R` (сброс).
Кнопка «Сброс ракурса» доступна также без клавиатуры.

Очистка изменяет цвет отложений, шероховатость и свечение непосредственно
на 3D-модели. Шкала этапов показывает путь от очистки к архивированию.
Надписи дешифровки отрисованы в SVG и не требуют поддержки редких знаков в
системном шрифте. Старые сохранения совместимы.

Новые модули:
- `src/relic-model.js` — общие модели, процедурный микрорельеф, объединение деталей и освобождение ресурсов;
- `src/inspection.js` — рендер по изменениям, управление осмотром, переиспользование контекста;
- `src/glyphs.js` — векторные символы и доступные названия;
- `scripts/inspection-check.mjs` — специализированный браузерный цикл (`npm run test:inspection`).

Актуальный критический отчёт продолжения: [docs/QA-LAB.md](docs/QA-LAB.md).

## Итерация 02 — очистка участков и полевые наблюдения

В лаборатории появились два инструмента: **Обзор** и **Кисть**. В режиме
кисти удерживайте указатель на модели: raycast определяет верхний,
центральный или нижний участок. Пустой фон не очищает находку. Для поворота
вернитесь в «Обзор». Каждый участок имеет собственный сохраняемый прогресс;
очистка раскрывает один знак и одно наблюдение о предмете.

Кнопочное управление остаётся полноценной альтернативой: выберите «Верх»,
«Центр», «Низ» или «Все участки» и удерживайте кнопку очистки либо Enter.
Дешифровка открывается после очистки всех трёх участков. Старые сохранения
автоматически преобразуются в новую схему без сброса процента очистки.

Материал отложений использует маску в локальных координатах модели:
очищенные области не перемещаются по поверхности при вращении камеры.
Это **три крупные зоны**, а не попиксельная кисть или симуляция разрушения.
На телефоне полевые наблюдения свёрнуты в раскрываемый блок. При потере
WebGL-контекста лаборатории остаются резервный вид и кнопочная очистка.

- `src/excavation.js` — независимые зоны, валидация и миграция прогресса;
- `src/deposits.js` — шейдер отложений без дополнительных draw calls;
- `src/evidence.js` — девять наблюдений для трёх находок;
- `npm run test:excavation` — raycast, независимость зон, прерывание кисти,
  сохранение, мобильная компоновка и потеря/восстановление контекста.

Отчёт: [docs/QA-ITERATION-02.md](docs/QA-ITERATION-02.md).

## Обновление графики мира

Окружение получило сглаженные эродированные скалы, более подробные камни
переднего плана, ветровую рябь грунта, фаски крупных архитектурных блоков,
переработанный свет и атмосферную перспективу. У планеты и её колец
исправлено цветовое преобразование; высокочастотные полосы колец фильтруются.

Режим **«Высокое»** добавляет мягкий HDR bloom и MSAA промежуточных буферов
(до четырёх выборок, по возможностям WebGL). Интерфейс не проходит через bloom.
В режиме **«Производительность»** постобработка отключена, её буферы
освобождены; сохраняются ограничения DPR и отключение теней/пыли.

`npm run test:graphics` проверяет реальные кадры, фоторежим, смену качества,
мобильный размер, сканер и отсутствие ошибок шейдеров.
Подробности: [docs/QA-GRAPHICS.md](docs/QA-GRAPHICS.md).
