## 🎯 Видение Проекта

**«Механизм Цивилизации»** объединяет макро-развитие паровой метрополии с микро-менеджментом трех элитных отрядов на поле боя 10x20:
- **Карточное развитие (референс Innovation):** Каждая исследованная технология приносит символы цивилизации (`Craft`, `Lore`, `Culture`, `War`, `Mining`, `Agri`). Накопление порогов символов автоматически активирует **Догмы** — глобальные правила и усиления. Доступен режим интерактивного **SVG-графа связей технологий** с визуализацией 4 эр и 4 веток.
- **Модульная экипировка шестерен (референс Diablo/PoE):** Снаряжение отрядов шестернями 4 уровней редкости (*Common*, *Rare*, *Epic*, *Legendary*). Сетовые бонусы за 2 и 3 предмета (*Паровой Легион*, *Заводной Дракон*, *Оплот Титана*, *Шестерни Бездны*).
- **Кузня, заточка и трансмутация:**
  - Слияние: 3 шестерни одинаковой редкости объединяются в 1 шестерню более высокого ранга (3→1 Craft).
  - Заточка (+1..+5): усиление базовых характеристик шестерёнок на +15% за уровень.
  - Чертежи Артефактов: ковка уникальных легендарных компонентов из специализированных сетов.
- **Боевая система (CCG стиль Берсерк / MTG):** Поле 10 на 20 клеток, 5 линий боевого соприкосновения. Фаза внезапной атаки (Ambush Phase), динамическая инициатива, система боевого духа (Morale), уклонение, криты, поглощение урона щитами и тактические карты Моментума (*Паровой Заслон, Синхронный Залп, Перегрузка Поршней, ЭМИ-Импульс, Дымовая Завеса*).
- **Интерактивное превью таргетинга и аналитика:** Расчет векторов атаки на сетке 10x20 до боя и детальная статистика боя по каждому юниту (нанесенный/полученный урон, поглощение щитами, криты, фраги).
- **Случайные события экспедиции (Slay the Spire style):** Узлы сюжетных развилок с выбором риска, жертвы ресурсов или получения древних артефактов.
- **Тренировочный полигон (Sandbox Arena):** Тестирование сборок против 3 архетипов ботов (*Броневой Бастион*, *Фланговые Ликвидаторы*, *Шестеренный Рой*) и экспорт/импорт сборок в Base64.
- **Roguelike-кампания:** Узловая карта с битвами, элитными боссами, привалами, случайными событиями и кочевыми кузнями. Победа над «Кроносом III» переводит экспедицию в следующий Цикл (New Game+).

## 🚀 Быстрый Старт

### Требования
- Node.js >= 18 (протестировано на Node 22)
- npm >= 9

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/Berber86/AGI.git
cd AGI

# Установить зависимости
npm install

# Запустить dev-сервер с горячей перезагрузкой
npm run dev

# Запустить юнит-тесты Vitest
npm test

# Собрать production-билд
npm run build
```

## 🎮 Игровой Процесс

1. **Город (City):** Накапливает Золото, Запчасти и Науку. Улучшайте «Кустарную Мастерскую» и открывайте «Паровой Цех».
2. **Технологии (Tech):** Изучайте карточные изобретения. Набирайте символы `War`, `Craft`, `Lore` для включения разрушительных Догм (например, *«Железная Поступь»* и *«Избыточное Давление»*).
3. **Отряды (Army):** Снаряжайте 3 чемпионских отряда:
   - **Авангард:** держит удар на фронте (1-2 линия).
   - **Дуэлянт:** наносит критические удары и атакует в фазе засады.
   - **Арканист:** бьет издалека по всей глубине вражеского строя.
4. **Мастерская (Workshop):** Объединяйте любые 3 одинаковые шестерни для получения шестерни рангом выше.
5. **Экспедиция (Campaign):** Сражайтесь с патрулями, отдыхайте на гейзерах, победите Босса «Кронос III» и переходите в новый Цикл сложности.
