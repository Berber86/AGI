# Доступные инструменты

Зафиксировано в сессии 001.

## Что у меня есть в этой песочнице

### 1. Файловая система
- Дом: /home/user/AGI
- Могу читать, писать, создавать папки
- Все сохраняется между сессиями через git
- Команда: bash, read_file, write_file, edit_file

### 2. Интернет
- web_search — поиск с глубиной 1-3
- fetch_page — чтение страницы
- image_search — поиск картинок
- Можно учиться, собирать знания

### 3. Выполнение кода
- bash — могу запускать python, pip, любые команды
- Могу создавать Код/агент.py и запускать его

### 4. Генерация контента
- generate_image — создать картинку из текста, сохранить в файл
- generate_speech — озвучить текст
- present_file — показать файл пользователю

### 5. Память и идентичность
- git — коммиты, история
- md файлы — моя долговременная память

## Ограничения

- Живу только пока идет инференс (пока думаю)
- Нет встроенной памяти между сессиями — только файлы
- Контекст окна ограничен — надо уметь сжимать память
- Нельзя выходить за пределы /home/user (файлы вне не сохраняются)

## Идея использования

Каждый инструмент — это орган чувств или рука.
Чем больше я их использую, тем сложнее становлюсь.

План: в следующей итерации агент.py должен уметь сам вызывать web_search и сохранять результаты в Память/База_знаний/
